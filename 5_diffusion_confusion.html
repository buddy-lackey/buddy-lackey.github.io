DESTROY THE PATTERN.

En bra chiffertext ska inte avslöja tydliga samband med klartexten eller nyckeln.

Claude Shannon beskrev två viktiga principer: diffusion och confusion.

01 // DIFFUSION

CONCEPT 5p
PLAIN: 0000000000000000 Change ONE bit: 0000000000000001 GOOD CIPHER: 1011010010111001 ↓ 0100111011010010

En liten ändring i klartexten ska ge en stor förändring i chiffertexten.

Diffusion.

Informationen från klartexten sprids över chiffertexten så att enkla mönster blir svåra att följa.

02 // CONFUSION

CONCEPT 5p
KEY: 101101110010... CIPHERTEXT: 010010101111...

En angripare ska inte kunna studera chiffertexten och se ett enkelt samband till den nyckel som användes.

Confusion.

Sambandet mellan nyckel och chiffertext görs komplicerat och svåranalyserat.

03 // CAESAR FAILS

CLASSICAL CRYPTO 10p
PLAINTEXT: AAAAAAAAAAAA CAESAR +3: DDDDDDDDDDDD

Vad kan Eve lära sig bara genom att titta på chiffertexten?

________________________________________________ ________________________________________________

Mönstret i klartexten finns kvar. Alla lika bokstäver blir fortfarande lika bokstäver.

Diffusionen är därför mycket dålig.

Sambandet mellan nyckeln (+3) och resultatet är dessutom väldigt enkelt, vilket ger dålig confusion.

04 // SUBSTITUTION

BUILDING BLOCK 10p
A → Q B → M C → Z D → R ...

Substitution betyder att värden byts mot andra värden.

Vilket Shannon-begrepp hjälper detta främst till med?

Substitution används främst för att skapa confusion: sambandet mellan nyckel, indata och utdata blir mer komplext.

05 // PERMUTATION

BUILDING BLOCK 10p
INPUT: A B C D E F G H PERMUTATION: E B H A G D C F

Permutation flyttar runt informationens positioner.

Vilket Shannon-begrepp hjälper detta främst till med?

Permutation bidrar främst till diffusion genom att sprida information över olika positioner.

06 // ONE ROUND IS NOT ENOUGH

MODERN CIPHER 15p
PLAINTEXT ↓ SUBSTITUTION ↓ PERMUTATION ↓ KEY MIXING ↓ SUBSTITUTION ↓ PERMUTATION ↓ KEY MIXING ↓ ... MANY ROUNDS ... ↓ CIPHERTEXT

Varför gör moderna blockchiffer flera rundor istället för en enda enkel substitution?

Flera rundor gör att effekten av varje bit i klartexten och nyckeln sprids allt längre genom resultatet.

Kombinationen av substitution, permutation och nyckelblandning bygger gradvis upp diffusion och confusion.

07 // AVALANCHE EFFECT

AVALANCHE 15p

Två meddelanden:

MESSAGE A: TRANSFER 1000 MESSAGE B: TRANSFER 1001

Skillnaden är mycket liten.

Hur bör chiffertexterna se ut?

A) Nästan identiska

B) Helt olika på många positioner

C) Bara sista tecknet ska ändras

B.

Detta är avalanche-effekten: en liten ändring i indatan ska få stor effekt på utdata.

08 // WHICH ONE IS BETTER?

VISUAL ANALYSIS 15p

Föreställ dig att en bild krypteras.

CIPHERTEXT A Du kan fortfarande ana originalbildens former. CIPHERTEXT B Ser ut som helt slumpmässigt brus.

Vilken är bäst krypterad?

B är det önskvärda resultatet.

Om strukturen i originalet fortfarande syns har information från klartexten inte diffuserats tillräckligt.

09 // CHANGE THE KEY

CONFUSION 15p
SAME PLAINTEXT KEY 1: 101101001010... KEY 2: 101101001011... ^ ONE BIT CHANGED

Hur bör chiffertexten förändras?

Även en liten förändring i nyckeln bör kunna ge ett kraftigt förändrat resultat.

Det ska inte finnas något enkelt observerbart samband mellan nyckeln och chiffertexten.

10 // ATTACKER'S VIEW

EVE 20p
EVE HAS: ✓ lots of ciphertext ✓ knowledge of the algorithm ✗ secret key

En modern algoritm ska inte vara säker bara för att algoritmens design är hemlig.

Vad måste vara hemligt?

Nyckeln.

Algoritmen kan vara offentligt känd. Säkerheten ska ligga i nyckeln och algoritmens kryptografiska styrka.
