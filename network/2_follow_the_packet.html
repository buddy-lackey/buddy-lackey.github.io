Follow the Packet

Mål: Skilj på MAC-adress, IP-adress och portnummer och förklara hur data kapslas.

PC1 ansluter till en webbserver på Internet:

PC1
IP:   192.168.10.25
MAC:  AA:AA:AA:AA:AA:25

Default Gateway
IP:   192.168.10.1
MAC:  BB:BB:BB:BB:BB:01

Web Server
IP:   203.0.113.80
TCP:  443

PC1 öppnar https://203.0.113.80/. Följande information finns i trafiken:

Ethernet
  Destination: BB:BB:BB:BB:BB:01
  Source:      AA:AA:AA:AA:AA:25

IPv4
  Destination: 203.0.113.80
  Source:      192.168.10.25

TCP
  Destination Port: 443
  Source Port:      51832
UPPGIFT
  1. Vilka adresser hör till lager 2?
  2. Vilka adresser hör till lager 3?
  3. Vad betyder TCP-port 443 respektive 51832?
  4. Varför är destination MAC routerns MAC och inte webbserverns MAC?
  5. Vilken adressinformation måste bytas när trafiken lämnar det lokala Ethernet-segmentet?
  6. Ordna: HTTP-data, TCP-segment, IP-paket, Ethernet-frame, bitar.

Final challenge

Vilket påstående beskriver kommunikationen bäst?

A  MAC-adresserna används hela vägen till webbservern.
B  IP-adresserna används bara på det lokala nätverket.
C  MAC-adresser används hop-by-hop medan IP används för kommunikationen
   mellan avsändare och destination.
REVEAL DISCUSSION

C. Ethernet levererar framen på den aktuella länken. IP används för att adressera paketet genom det routade nätverket. När en router vidarebefordrar trafik tas den inkommande L2-framen bort och en ny L2-frame skapas för nästa länk.

Ordningen nedåt i stacken är: HTTP-data → TCP-segment → IP-paket → Ethernet-frame → bitar.
