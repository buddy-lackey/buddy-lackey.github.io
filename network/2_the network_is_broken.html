The Network Is Broken

Mål: Resonera om lokalt nät, ARP, default gateway och routing.

PC-ALPHA
IP address:      192.168.10.25
Subnet mask:     255.255.255.0
Default gateway: 192.168.10.1
DNS:             192.168.10.53

C:\> ping 192.168.10.40
Reply from 192.168.10.40

C:\> ping 192.168.20.40
Destination host unreachable.

C:\> arp -a
192.168.10.1     00-aa-bb-cc-dd-01
192.168.10.40    00-aa-bb-cc-dd-40
ANALYSERA
  1. Vilken destination är lokal för PC-ALPHA?
  2. Vilken destination kräver routing?
  3. Varför behöver PC:n inte känna till MAC-adressen för 192.168.20.40?
  4. Vilken MAC-adress behöver den istället?

Du får sedan tillgång till routern:

Router G0/0
IP address: 192.168.100.1/24
HITTA FELET: Varför fungerar inte kommunikationen till andra nät?
REVEAL DISCUSSION

PC:n är konfigurerad med 192.168.10.1 som default gateway, men routerns interface är 192.168.100.1/24. PC:n och dess gateway måste kunna kommunicera lokalt. Trafik till 192.168.20.40 skickas därför aldrig korrekt till en router.
