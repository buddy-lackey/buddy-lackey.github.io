INTER-VLAN
ROUTING CHALLENGE

Four architectures. Same networks. Different solutions.

● NETWORK LAB ONLINE_

// THE MISSION

Ett företag har tre avdelningar som ligger i separata VLAN. De ska kunna kommunicera med varandra, men en vanlig Layer 2-switch kan inte routa trafik mellan VLAN.

Din uppgift är att lösa problemet på fyra olika sätt i Cisco Packet Tracer.

Regel: Använd samma IP-plan genom hela utmaningen. Bygg gärna varje nivå i en separat Packet Tracer-fil.

// NETWORK SPECIFICATION

Gemensam IP-plan

VLANNätverkGateway
10 – ADMIN192.168.10.0/24192.168.10.1
20 – SALES192.168.20.0/24192.168.20.1
30 – IT192.168.30.0/24192.168.30.1

Exempel: PC10 = 192.168.10.10, PC20 = 192.168.20.10, PC30 = 192.168.30.10. Alla använder /24.

Starttest: Kontrollera att datorer i olika VLAN inte kan pinga varandra innan routing konfigureras.

// LEVEL 01
CHALLENGE 01 // LEGACY

One interface per VLAN

Den första lösningen använder ett separat fysiskt routerinterface för varje VLAN.

Din uppgift

  1. Placera en router, en Layer 2-switch och tre datorer.
  2. Skapa VLAN 10, 20 och 30 på switchen.
  3. Konfigurera accessportar för datorerna.
  4. Anslut varje VLAN till ett eget fysiskt routerinterface via en accessport.
  5. Konfigurera IP-adresser på routerinterfacen.
  6. Konfigurera datorernas IP-adresser och default gateway.
  7. Verifiera kommunikation mellan alla tre VLAN.

Tips: Välj en routermodell med minst tre användbara Ethernet-interface. Moduler kan behövas.

Verifiering

show ip interface brief
show ip route
show vlan brief

PC10 > ping 192.168.20.10
PC10 > ping 192.168.30.10
Reveal discussion

Varje routerinterface fungerar som gateway för sitt VLAN. Lösningen fungerar, men kräver ett nytt fysiskt interface för varje ytterligare VLAN. Det gör den svår att skala.

// LEVEL 02
CHALLENGE 02 // ROUTER-ON-A-STICK

One link. Multiple VLANs.

Nu ska du lösa samma problem med endast en fysisk anslutning mellan router och switch.

Din uppgift

  1. Skapa samma tre VLAN och anslut samma tre datorer.
  2. Använd en enda fysisk anslutning mellan router och switch.
  3. Konfigurera switchporten som 802.1Q-trunk.
  4. Skapa ett subinterface på routern för varje VLAN.
  5. Konfigurera encapsulation dot1Q med rätt VLAN-ID.
  6. Tilldela varje subinterface rätt gateway-adress.
  7. Verifiera att datorerna kan kommunicera mellan VLAN.

Verifiering

show interfaces trunk
show ip interface brief
show ip route

PC10 > ping 192.168.20.10
PC20 > ping 192.168.30.10
Reveal discussion

Subinterfacen är logiska gränssnitt på samma fysiska routerinterface. 802.1Q identifierar vilket VLAN varje Ethernet-frame tillhör.

Fördelen är att flera VLAN delar en fysisk anslutning. Nackdelen är att trafik mellan VLAN måste passera samma länk till routern och tillbaka.

// LEVEL 03
CHALLENGE 03 // LAYER 3 SWITCH

Routing inside the switch

Routern är borta. Nu ska Layer 3-switchen själv utföra routingen.

Din uppgift

  1. Välj en multilayer-switch, exempelvis Cisco 3560.
  2. Skapa VLAN 10, 20 och 30.
  3. Konfigurera accessportar för datorerna.
  4. Skapa ett SVI för varje VLAN med rätt IP-adress.
  5. Aktivera IP-routing på switchen.
  6. Konfigurera datorernas default gateway.
  7. Verifiera kommunikation mellan alla VLAN.

Verifiering

show vlan brief
show ip interface brief
show ip route

PC10 > ping 192.168.20.10
PC10 > ping 192.168.30.10
Reveal discussion

Ett SVI är ett virtuellt Layer 3-interface kopplat till ett VLAN. IP-adressen på SVI:t fungerar som gateway.

Med kommandot ip routing kan switchen routa mellan sina direktanslutna VLAN-subnät utan en extern router.

// FINAL LEVEL
BOSS CHALLENGE // CISCO ASA

Routing is not permission

Företaget har infört en brandvägg. Nu räcker det inte att routa mellan nätverken. Du ska också undersöka vilken trafik brandväggen tillåter.

Boss-scenario: ADMIN och SALES ligger i olika VLAN. ADMIN ska kunna initiera kommunikation till SALES, men SALES ska inte automatiskt kunna initiera nya anslutningar till ADMIN.

Din uppgift

  1. Placera en Cisco ASA 5505, en Layer 2-switch och två datorer.
  2. Använd VLAN 10 och VLAN 20 från IP-planen.
  3. Skapa två VLAN-interface på ASA med rätt IP-adresser.
  4. Anslut ASA till switchen med två separata accessanslutningar, en för varje VLAN.
  5. Konfigurera nameif och olika security-level på VLAN-interfacen.
  6. Konfigurera datorernas IP-adresser och default gateway.
  7. Undersök vilka pingtester som fungerar och vilka som blockeras.
  8. Förklara skillnaden mellan routing och tillåten trafik.

Packet Tracer simulerar ASA 5505 med begränsad funktionalitet. Denna grunduppgift använder därför separata accessanslutningar, inte en 802.1Q-trunk. Exakta pingresultat kan påverkas av ASA:s ICMP-hantering och simulatorversion.

Verifiering

show interface ip brief
show running-config
show route

PC10 > ping 192.168.20.10
PC20 > ping 192.168.10.10
Reveal discussion

ASA kan routa mellan direktanslutna VLAN-subnät, men säkerhetspolicyer avgör vilken trafik som får passera.

Med olika security levels tillåter ASA normalt nya anslutningar från högre till lägre säkerhetsnivå, men inte omvänt utan uttrycklig tillåtelse.

ICMP kräver särskild uppmärksamhet. Ett misslyckat ping betyder därför inte nödvändigtvis att routingen är fel.

Bonus: Undersök om din ASA-version stöder 802.1Q-trunk. Jämför i så fall arkitekturen med router-on-a-stick.

// FINAL DEBRIEF

Which architecture would you choose?

Du har nu byggt flera lösningar på samma nätverksproblem.

  1. Vilken metod kräver flest fysiska routerinterface?
  2. Vilken metod använder subinterface och 802.1Q?
  3. Vilken metod routar internt i switchen?
  4. Varför kan en brandvägg blockera trafik trots att det finns en fungerande route?
  5. Vilken metod skulle du välja för ett större företagsnät med mycket intern trafik? Varför?
  6. När är det motiverat att låta trafik mellan VLAN passera en brandvägg?
Reveal discussion

Legacy kräver ett fysiskt routerinterface per VLAN. Router-on-a-stick använder 802.1Q och subinterface. Layer 3-switchen använder SVI och intern routing.

En brandvägg kan utföra samma grundläggande routing, men kan också kontrollera kommunikationen med säkerhetspolicyer.

I större företagsnät är Layer 3-switchar vanliga för högpresterande intern routing. Brandväggar används ofta där trafiken behöver säkerhetskontrolleras.
