BASIC // MISSION 01

EXPLORE THE INTERFACE

Starta Cisco Packet Tracer och skapa ett nytt tomt projekt.

Klicka runt i programmet innan du bygger något.

TASK 01
Hitta kategorin End Devices.
TASK 02
Hitta kategorin Network Devices.
TASK 03
Hitta switchar och routrar.
TASK 04
Hitta Connections / kablar.
TASK 05
Hitta Realtime och Simulation Mode.
Vad tror du skillnaden är mellan Realtime och Simulation?
Realtime låter nätverket fungera löpande. Simulation Mode kan användas för att observera hur trafik och protokollhändelser rör sig genom nätverket.
BASIC // MISSION 02

PLACE YOUR FIRST DEVICES

Placera följande enheter:

2 × PC
1 × Switch

Döp dem gärna till:

PC-A
PC-B
SW-01
PC-A SW-01 PC-B

Än så länge finns inga anslutningar.

Vilka av enheterna är slutenheter?
PC-A och PC-B. De skapar eller tar emot data.
BASIC // MISSION 03

CONNECT THE DEVICES

Anslut båda datorerna till switchen.

PC-A ─────────┐ │ SW-01 │ PC-B ─────────┘
Observera vilka portar Packet Tracer använder.

Du bör få något som liknar:

PC-A FastEthernet0
        │
        ▼
SW-01 FastEthernet0/1
Vilken roll har switchen?
Switchen är en mellanliggande nätverksenhet som sammankopplar enheter i nätverket.
INTERMEDIATE // MISSION 04

CONFIGURE IP

Nu behöver datorerna adresser.

Öppna PC-A och konfigurera: 

IP Address: 192.168.10.10
Subnet Mask: 255.255.255.0

Konfigurera PC-B:

IP Address: 192.168.10.20
Subnet Mask: 255.255.255.0
PC-A 192.168.10.10 │ │ SW-01 │ │ PC-B 192.168.10.20
Subnetting behandlas mer senare. Just nu räcker det att båda datorerna ligger i samma 192.168.10.x-nät med samma subnet mask.
INTERMEDIATE // MISSION 05

OPEN THE COMMAND PROMPT

Öppna PC-A och leta upp dess Command Prompt.

Kör:

ipconfig

Försök identifiera IP-adressen du precis konfigurerade.

PC> ipconfig IP Address...................... 192.168.10.10 Subnet Mask..................... 255.255.255.0
Är kommandot information om PC-A eller switchen?
PC-A. Du kör kommandot på slutenheten.
INTERMEDIATE // MISSION 06

FIRST PING

Från PC-A: 

ping 192.168.10.20
PC-A 192.168.10.10 │ │ PING ▼ SW-01 │ ▼ PC-B 192.168.10.20

Om nätverket är korrekt byggt bör PC-B svara.

Det första försöket kan ibland bete sig annorlunda medan nätverket lär sig information som behövs för kommunikationen. Testa ping igen innan du börjar felsöka.
Vad har du precis verifierat?
Att PC-A och PC-B kan kommunicera över det nätverk du byggt.
CHALLENGE // MISSION 07

BREAK THE NETWORK

Nu ska du medvetet skapa ett fel.

Ändra PC-B till: 

192.168.20.20

Kör sedan från PC-A:

ping 192.168.20.20
PC-A PC-B 192.168.10.10 192.168.20.20 │ │ └──────── SW-01 ──────────┘ SAME SWITCH DIFFERENT IP NETWORKS
Fungerar kommunikationen fortfarande på samma sätt?
Datorerna är nu konfigurerade för olika IP-nät. En switch ensam routar inte IP-trafik mellan olika nät. För det behövs routing. Återställ PC-B till 192.168.10.20 efter testet.
CHALLENGE // MISSION 08

ENTER SIMULATION MODE

Återställ först: 

PC-A: 192.168.10.10
PC-B: 192.168.10.20

Byt sedan från Realtime till Simulation.

Skicka trafik mellan PC-A och PC-B.

SOURCE PC-A │ │ packet ▼ SW-01 │ │ packet ▼ PC-B DESTINATION
Observera vilken väg trafiken tar.
Identifiera source och destination.
Identifiera den mellanliggande enheten.
Klicka på ett paket/event och undersök vilken information Packet Tracer visar.
Kan du nu se skillnaden mellan en slutenhet och en mellanliggande nätverksenhet?
PC-A och PC-B är ändpunkterna. SW-01 är en mellanliggande enhet som hjälper kommunikationen att färdas mellan dem.
BOSS // MISSION 09

BUILD WITHOUT INSTRUCTIONS

Nu får du bara en kravspecifikation.

NETWORK REQUEST: NET-BOOT-01 Build a small office network. REQUIREMENTS: 4 × PC 1 × Switch NETWORK: 192.168.50.0/24 All PCs must communicate.

Du bestämmer själv adresserna.

Placera ut alla enheter.
Koppla nätverket.
Konfigurera fyra unika IP-adresser.
Verifiera konfigurationen med ipconfig.
Verifiera kommunikationen med ping.
Använd Simulation Mode och följ trafik mellan två datorer.
