ROUTING CHALLENGE

The Missing Route // Packet Tracer
MISSION BRIEFING

Två LAN. Två routrar. Ingen kommunikation.

Du är nätverkstekniker och ska koppla samman två lokala nätverk. Alla enheter är korrekt anslutna, men datorerna kan ännu inte kommunicera.

Ditt uppdrag är att konfigurera IP-adresser, undersöka routingtabeller och skapa fungerande routing mellan nätverken.

Tidsåtgång: cirka 60–90 minuter.

Verktyg: Cisco Packet Tracer.

NETWORK TOPOLOGY

Bygg nätverket

PC1 R1 R2 PC2 | | | | | | | | +--- SW1 ----+---------------+---- SW2 ----+ LAN A TRANSIT LAN B

Använd två Cisco-routrar, två switchar och två datorer. Koppla routrarna direkt till varandra med Ethernet.

IP-plan

EnhetInterface IP-adressGateway
PC1Ethernet 192.168.10.10/24 192.168.10.1
R1G0/0 192.168.10.1/24–
R1G0/1 10.0.0.1/30–
R2G0/0 10.0.0.2/30–
R2G0/1 192.168.20.1/24–
PC2Ethernet 192.168.20.10/24 192.168.20.1

Kontrollera interfacenamnen på din routermodell. De kan skilja sig från tabellen.

CHALLENGE 01

Configure the Interfaces

Konfigurera IP-adresserna på routrarnas interface enligt IP-planen.

Glöm inte att aktivera interfacen.

Verifiera

show ip interface brief
show ip route

Besvara följande frågor:

  1. Vilka interface är up/up?
  2. Vilka nät finns i routingtabellen?
  3. Vad betyder bokstaven C i routingtabellen?
  4. Vad betyder bokstaven L?
REVEAL DISCUSSION

C betyder Connected och visar ett direktanslutet nätverk. L betyder Local och visar routerns egen IP-adress som en /32-route. 

interface gigabitEthernet0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown

Exemplet gäller R1:s LAN-interface. Övriga interface konfigureras på motsvarande sätt.

CHALLENGE 02

The Missing Route

Konfigurera PC1 och PC2 enligt IP-planen. Kontrollera först att datorerna når sina respektive default gateways. 

ping 192.168.10.1

Försök sedan pinga PC2 från PC1. 

ping 192.168.20.10

Undersök följande:

  1. Varför fungerar ping till default gateway?
  2. Varför fungerar inte ping till PC2?
  3. Vilken information saknas i R1?
  4. Vilken information saknas i R2?
REVEAL DISCUSSION

R1 känner endast till sina direktanslutna nät. Den saknar en route till 192.168.20.0/24.

R2 saknar motsvarande route till 192.168.10.0/24.

Routrarna behöver information om både framvägen och returvägen.

CHALLENGE 03

Static Routing

Konfigurera statiska routes så att R1 känner till LAN B och R2 känner till LAN A.

Använd nästa routers IP-adress som next hop.

HINT – Static route syntax 
ip route NETWORK MASK NEXT-HOP

Verifiera med:

show ip route
ping 192.168.20.10
REVEAL SOLUTION

R1

configure terminal
ip route 192.168.20.0 255.255.255.0 10.0.0.2
end

R2

configure terminal
ip route 192.168.10.0 255.255.255.0 10.0.0.1
end

Kontrollera att S visas i routingtabellen. S betyder Static.

CHALLENGE 04

Follow the Packet

Växla till Simulation Mode i Packet Tracer. Filtrera gärna på ARP och ICMP.

Skicka ett ping från PC1 till PC2 och följ paketet genom nätverket.

  1. Vilken MAC-adress använder PC1 som destination?
  2. Ändras IP-paketets destinationsadress?
  3. Vad händer med Ethernet-headern i R1?
  4. Vad händer med TTL när paketet routas?
  5. Varför behöver routern göra ARP?
REVEAL DISCUSSION

PC1 skickar ramen till sin default gateway, eftersom PC2 finns i ett annat IP-nät.

Routern tar bort den inkommande Ethernet- inkapslingen och skapar en ny för nästa länk.

IP-destinationsadressen är fortfarande PC2. TTL minskas med ett för varje routerhopp.

ARP används för att hitta nästa hops MAC-adress på Ethernet-länken.

BOSS CHALLENGE

Broken Network

En kollega har råkat konfigurera fel next-hop-adress på R1.

Ta bort den fungerande statiska routen på R1 och lägg till följande felaktiga route: 

configure terminal
no ip route 192.168.20.0 255.255.255.0 10.0.0.2
ip route 192.168.20.0 255.255.255.0 10.0.0.6
end

Din uppgift är att felsöka och återställa kommunikationen.

  1. Undersök R1:s routingtabell.
  2. Kontrollera next-hop-adressen.
  3. Förklara varför routen inte fungerar.
  4. Återställ korrekt routing.
  5. Verifiera med ping och tracert.
REVEAL SOLUTION

10.0.0.6 är inte en nåbar next hop i den aktuella topologin. Den statiska routen kan därför inte användas. 

configure terminal
no ip route 192.168.20.0 255.255.255.0 10.0.0.6
ip route 192.168.20.0 255.255.255.0 10.0.0.2
end
BONUS CHALLENGE

Dynamic Routing – RIPv2

Hittills har ni manuellt berättat för routrarna var de olika nätverken finns.

Men vad händer om nätverket växer till 20 eller 100 routrar?

Undersök hur RIPv2 kan användas för att automatiskt utbyta routinginformation.

REVEAL CONFIGURATION

R1

configure terminal
no ip route 192.168.20.0 255.255.255.0 10.0.0.2
router rip
 version 2
 no auto-summary
 network 192.168.10.0
 network 10.0.0.0
end

R2

configure terminal
no ip route 192.168.10.0 255.255.255.0 10.0.0.1
router rip
 version 2
 no auto-summary
 network 192.168.20.0
 network 10.0.0.0
end

Kontrollera routingtabellen efter att routrarna har utbytt information. 

show ip route
show ip protocols

Routes som lärts in via RIP markeras med bokstaven R.
