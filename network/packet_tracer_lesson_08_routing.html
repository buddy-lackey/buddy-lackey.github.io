ROUTING CHALLENGE

The Missing Route // Cisco Packet Tracer
MISSION BRIEFING

Två LAN. Två routrar. Ingen kommunikation.

Du är nätverkstekniker och ska koppla samman två lokala nätverk.

Datorerna i respektive LAN ska kunna kommunicera med varandra, trots att de befinner sig i olika IP-nät.

Ditt uppdrag är att bygga nätverket, konfigurera IP-adresser, undersöka routingtabeller och skapa fungerande routing mellan nätverken.

Tidsåtgång: cirka 60–90 minuter.

Verktyg: Cisco Packet Tracer.

Rekommenderad utrustning:

  • 2 × Cisco 2911 Router
  • 2 × Cisco 2960 Switch
  • 2 × PC
Målet är inte bara att få ping att fungera. Du ska också kunna förklara varför routing behövs och hur routrarna fattar beslut.
NETWORK TOPOLOGY

Bygg nätverket

Bygg följande topologi i Packet Tracer. Använd Ethernet-kablar och anslut enheterna enligt diagrammet.

Viktigt: SW1 och SW2 är Layer 2-switchar. R1 och R2 ansvarar för routing mellan IP-näten.

IP-plan

Enhet Interface IP-adress Default gateway
PC1 FastEthernet0 192.168.10.10/24 192.168.10.1
R1 G0/0 192.168.10.1/24 –
R1 G0/1 10.0.0.1/30 –
R2 G0/0 10.0.0.2/30 –
R2 G0/1 192.168.20.1/24 –
PC2 FastEthernet0 192.168.20.10/24 192.168.20.1

Använd Cisco 2911 om möjligt. Andra routermodeller kan ha andra interfacenamn.

CHALLENGE 01

Configure the Interfaces

Konfigurera IP-adresserna på samtliga routerinterface enligt IP-planen.

Aktivera interfacen med no shutdown.

Konfigurera även PC1 och PC2 med IP-adress, nätmask och default gateway.

Verifiera

show ip interface brief
show ip route
  1. Vilka interface är up/up?
  2. Vilka nät finns i routingtabellen?
  3. Vad betyder C i routingtabellen?
  4. Vad betyder L i routingtabellen?
REVEAL DISCUSSION

C = Connected: ett direktanslutet nätverk.

L = Local: routerns egen IP-adress, normalt representerad som en /32-route.

Exempel: R1 LAN

enable
configure terminal
interface gigabitEthernet0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
end

Konfigurera övriga routerinterface på motsvarande sätt.

CHALLENGE 02

The Missing Route

Nu ska du undersöka vilka delar av nätverket som fungerar innan någon statisk routing har konfigurerats.

Test 1 – Lokal gateway

Öppna Command Prompt på PC1. 

ping 192.168.10.1

Testa motsvarande från PC2. 

ping 192.168.20.1

Test 2 – Transitlänken

Öppna CLI på R1 och testa kommunikation med R2. 

ping 10.0.0.2

Fungerar kommunikationen mellan routrarna?

Test 3 – Mellan LAN A och LAN B

Gå tillbaka till PC1 och testa: 

ping 192.168.20.10

Frågor

  1. Fungerar kommunikationen till lokal gateway?
  2. Fungerar transitlänken mellan R1 och R2?
  3. Varför fungerar inte kommunikationen mellan PC1 och PC2?
  4. Vilket nät saknas i R1:s routingtabell?
  5. Vilket nät saknas i R2:s routingtabell?
REVEAL DISCUSSION

R1 känner till två direktanslutna nät: 192.168.10.0/24 och 10.0.0.0/30.

R2 känner till två direktanslutna nät: 10.0.0.0/30 och 192.168.20.0/24.

Transitlänken fungerar, men R1 känner inte till LAN B och R2 känner inte till LAN A.

Routrarna behöver routinginformation för att kunna skicka paket mellan näten.

CHALLENGE 03

Static Routing

Konfigurera statiska routes så att R1 känner till LAN B och R2 känner till LAN A.

Använd nästa routers IP-adress som next hop.

HINT – Static route syntax 
ip route NETWORK MASK NEXT-HOP

Verifiera

show ip route

Kontrollera att routrarna har lärt sig hur de når det andra LAN-nätet.

Testa därefter från PC1: 

ping 192.168.20.10
REVEAL SOLUTION

R1

configure terminal
ip route 192.168.20.0 255.255.255.0 10.0.0.2
end

R2

configure terminal
ip route 192.168.10.0 255.255.255.0 10.0.0.1
end

Statiska routes markeras med bokstaven S i routingtabellen.

Både framvägen och returvägen måste fungera.

CHALLENGE 04

Follow the Packet

Växla till Simulation Mode i Packet Tracer. Filtrera på ARP och ICMP.

Skicka ett ping från PC1 till PC2 och följ paketet genom nätverket.

  1. Vilken MAC-adress använder PC1 som destination?
  2. Ändras IP-paketets destinationsadress?
  3. Vad händer med Ethernet-headern i R1?
  4. Vad händer med TTL när paketet passerar en router?
  5. Varför behöver routern använda ARP?
REVEAL DISCUSSION

PC1 skickar Ethernet-ramen till sin default gateway eftersom PC2 finns i ett annat IP-nät.

Routern tar bort den inkommande Ethernet-inkapslingen och skapar en ny Ethernet-ram för nästa länk.

IP-destinationsadressen förblir densamma, men TTL minskar med ett för varje routerhopp.

ARP används för att hitta nästa hops MAC-adress på det lokala Ethernet-nätet.

Observera att den första pingningen kan misslyckas medan ARP-tabellerna byggs upp i Packet Tracer. Testa i så fall igen.

BOSS CHALLENGE

Broken Network

En kollega har råkat konfigurera en felaktig next-hop-adress på R1.

Ersätt R1:s fungerande route med följande felaktiga route: 

configure terminal
no ip route 192.168.20.0 255.255.255.0 10.0.0.2
ip route 192.168.20.0 255.255.255.0 10.0.0.6
end

Felsökningsuppdrag

  1. Testa ping från PC1 till PC2.
  2. Undersök R1:s routingtabell.
  3. Undersök R1:s konfiguration.
  4. Jämför den konfigurerade routen med routingtabellen.
  5. Förklara varför kommunikationen misslyckas.
  6. Återställ korrekt routing.
  7. Verifiera med ping och tracert.

Användbara kommandon

show ip route
show running-config
show ip interface brief
En statisk route kan finnas i konfigurationen utan att vara installerad i routingtabellen. Fundera på varför.
REVEAL SOLUTION

10.0.0.6 är inte en nåbar next hop i den aktuella topologin.

Den felaktiga routen kan därför finnas i running-config men saknas i den aktiva routingtabellen.

Återställ korrekt routing på R1: 

configure terminal
no ip route 192.168.20.0 255.255.255.0 10.0.0.6
ip route 192.168.20.0 255.255.255.0 10.0.0.2
end

Kontrollera att routen återkommer i routingtabellen och att PC1 åter kan nå PC2.

BONUS CHALLENGE

Dynamic Routing – RIPv2

Hittills har routrarna fått manuella instruktioner om var nätverken finns.

Men vad händer om nätverket växer till 20 eller 100 routrar?

Undersök hur RIPv2 kan användas för att automatiskt utbyta routinginformation.

RIPv2 används här som ett pedagogiskt exempel på dynamisk routing. I moderna produktionsnät är exempelvis OSPF ofta ett mer relevant alternativ.
REVEAL CONFIGURATION

R1

configure terminal
no ip route 192.168.20.0 255.255.255.0 10.0.0.2
router rip
 version 2
 no auto-summary
 network 192.168.10.0
 network 10.0.0.0
end

R2

configure terminal
no ip route 192.168.10.0 255.255.255.0 10.0.0.1
router rip
 version 2
 no auto-summary
 network 192.168.20.0
 network 10.0.0.0
end

Vänta tills routrarna har utbytt routinginformation. 

show ip route
show ip protocols

Routes som lärts in via RIP markeras med bokstaven R i routingtabellen.
