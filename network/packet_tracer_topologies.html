BASIC // MISSION 02

IS THIS P2P?

Du har byggt:

PC0 ⇄ PC1
Är nätverket automatiskt en Peer-to-Peer-arkitektur bara för att datorerna är direkt sammankopplade?
Nej. Hur datorerna är fysiskt sammankopplade och hur applikationerna organiseras är två olika saker. I en P2P-arkitektur kan noder exempelvis både konsumera och erbjuda resurser/tjänster. En direkt kabel mellan två datorer demonstrerar därför inte automatiskt en fullständig P2P-applikationsarkitektur.
REMEMBER: PHYSICAL CONNECTION ≠ APPLICATION ARCHITECTURE

CHALLENGE // MISSION 05

BREAK THE STAR

INCIDENT SIMULATION ENABLED Du ska nu medvetet skapa fel i nätverket.

TEST A // CLIENT LINK FAILURE

Koppla bort anslutningen mellan PC0 och SWITCH0.

PC0 ─── X ─── SWITCH0 PC1 ──────────┤ PC2 ──────────┤ PC3 ──────────┘
Vilka datorer påverkas?

Återställ anslutningen.

TEST B // CENTRAL FAILURE

Stäng av SWITCH0 eller simulera att den centrala switchen inte fungerar.

PC0 │ X PC1 ───── [ SWITCH0 ] X PC2 ───────────┤ │ PC3 SWITCH FAILURE
Vad händer nu?
Varför blir konsekvensen större än när en enda PC-kabel kopplades bort?
När en klientlänk går sönder påverkas främst den anslutna klienten. När den centrala switchen slutar fungera påverkas alla enheter som är beroende av den. Den centrala noden är därför en viktig felpunkt i den här enkla stjärntopologin.
CHALLENGE // MISSION 06

BUILD A TREE

OBJECTIVE: Skala upp nätverket genom att koppla samman flera stjärnor.
SW-CORE / \ / \ SW-A SW-B / | \ / | \ / | \ / | \ PC0 PC1 PC2 PC3 PC4 PC5
Placera tre switchar.
Använd en switch som central switch: SW-CORE.
Anslut SW-A och SW-B till SW-CORE.
Anslut tre datorer till varje access-switch.

Du kan exempelvis använda: 

PC0  192.168.40.10 /24
PC1  192.168.40.11 /24
PC2  192.168.40.12 /24

PC3  192.168.40.20 /24
PC4  192.168.40.21 /24
PC5  192.168.40.22 /24
Vilken topologi börjar detta likna?
En trädtopologi. Flera stjärnor har kopplats samman i en hierarkisk struktur.

FAILURE TEST

Test Gör så här
A Koppla bort PC0.
B Koppla bort SW-A från SW-CORE.
C Stäng av SW-CORE.
Hur många enheter påverkas i respektive scenario?
Vilket fel får störst konsekvens?
Ett fel längre upp i hierarkin kan påverka fler enheter. PC0-fel: främst PC0. SW-A eller länken uppåt: hela grenen under SW-A kan påverkas. SW-CORE: kommunikation som är beroende av den centrala switchen påverkas.
OPTIONAL // SIDE QUEST

WHAT ABOUT A RING?

I teorin har du även gått igenom ringtopologi.

NODE-A ───────── NODE-B │ │ │ │ │ │ NODE-D ───────── NODE-C
Bygg inte automatiskt en fysisk Ethernet-loop mellan flera switchar och anta att du därmed har återskapat klassisk Token Ring. Moderna switchade Ethernet-nät och klassiska ringnät är inte samma sak.

Om läraren demonstrerar en fysisk loop mellan switchar: observera vad Packet Tracer gör.

Varför tror du att loopar kan vara problematiska i Ethernet-nät?
Detta leder vidare till tekniker som Spanning Tree Protocol. STP behandlas senare om det ingår i kursen. Poängen just nu är att en fysisk form som ser ut som en ring inte automatiskt betyder att nätverket fungerar som klassisk Token Ring.
