HEXADECIMAL:
SPEAK MAC

Lär dig precis så mycket hexadecimal representation och binärt som behövs för att kunna läsa och förstå MAC-adresser.

MÅL
Efter övningen ska du kunna läsa hexadecimala värden, förstå hur de representerar bitar och bytes samt använda detta för att resonera om MAC-adresser.

1. Varför hexadecimal?

Fyra bitar kan representeras med exakt en hexadecimal siffra.

1111 1111 = FF hex = 255 decimal

2. Räkna lite hex

2A hex = 2 × 16 + 10 = 42 decimal
CHALLENGE 1 — HEX → DECIMAL
0A = ?
10 = ?
2A = ?
FF = ?
REVEAL ANSWER
0A = 10
10 = 16
2A = 42
FF = 255

3. Från hex till MAC

00 : 08 : A2 : BC : 56 : D3
──   ──   ──   ──   ──   ──
1B   1B   1B   1B   1B   1B

6 bytes × 8 bitar = 48 bitar
12 hexsiffror
CHALLENGE 2 — DISSECT THE MAC

Utgå från 00:08:A2:BC:56:D3.

  1. Hur många bytes?
  2. Hur många bitar?
  3. Hur många hexsiffror?
  4. Vad är 00 i decimal?
  5. Vad är D3 i decimal?
REVEAL ANSWER
6 bytes
48 bitar
12 hexsiffror
00 = 0
D3 = 13 × 16 + 3 = 211

4. Hitta I/G-biten

Första byte
    ↓
    00
    ↓
0000 0000
       ↑
       I/G-bit

I/G = 0 → Individual → Unicast
I/G = 1 → Group      → Multicast
Första byteBinärtI/GTyp
000000 00000Individual / Unicast
010000 00011Group / Multicast
080000 10000Individual / Unicast
3C0011 11000Individual / Unicast
3D0011 11011Group / Multicast
GENVÄG: Jämnt värde i första byten → I/G=0. Udda värde → I/G=1. En unicast-MAC behöver alltså inte börja med 00.

5. Unicast eller multicast?

CHALLENGE 3 — FIND THE BIT
00 = ?
01 = ?
08 = ?
3C = ?
3D = ?
A4 = ?
A5 = ?

Förklara svaret med I/G-biten.

REVEAL ANSWER
00 → I/G 0 → Individual / Unicast
01 → I/G 1 → Group / Multicast
08 → I/G 0 → Individual / Unicast
3C → I/G 0 → Individual / Unicast
3D → I/G 1 → Group / Multicast
A4 → I/G 0 → Individual / Unicast
A5 → I/G 1 → Group / Multicast

6. Final challenge — MAC detective

CHALLENGE 4
A) 00:08:A2:BC:56:D3
B) 01:00:5E:00:00:C8
C) 3C:52:82:11:22:33
D) 3D:52:82:11:22:33
E) FF:FF:FF:FF:FF:FF
  1. Vilka är Individual/Unicast?
  2. Vilka är Group/Multicast?
  3. Vilken är Ethernet broadcast?
  4. Vilken bit behöver du undersöka?
REVEAL FINAL ANSWER
A → Individual / Unicast
B → Group / Multicast
C → Individual / Unicast
D → Group / Multicast
E → Ethernet broadcast

Undersök I/G-biten, den minst signifikanta biten i första byten.

7. Ta med dig detta

1 hexsiffra = 4 bitar
2 hexsiffror = 1 byte
MAC = 6 bytes = 48 bitar = 12 hexsiffror

I/G = 0 → Individual / Unicast
I/G = 1 → Group / Multicast

FF:FF:FF:FF:FF:FF → Ethernet Broadcast

Nästa steg: använd samma kunskap när du analyserar riktiga Ethernet-frames och switchens MAC-adresstabell.
