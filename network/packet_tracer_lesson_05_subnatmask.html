LECTURE 05 // IPv4

Packet Tracer: subnätmask

● NETWORK ONLINE_

Cirka 35–50 minuter · Arbeta ensam eller i par

Du ska visa vad som händer när ett /24 delas i två /25-nät utan att IP-adresser eller kablar ändras.

// STEP 01 — Bygg startmiljön

Placera en lager 2-switch, exempelvis 2960, och fyra PC. Anslut varje PC till en egen switchport med Copper Straight-Through. Behåll alla portar i samma VLAN. Lägg inte till någon router.

PCIP-adressNätmaskGateway
PC1192.168.1.10255.255.255.0Tom
PC2192.168.1.11255.255.255.0Tom
PC3192.168.1.240255.255.255.0Tom
PC4192.168.1.241255.255.255.0Tom

Ange adresserna under Desktop → IP Configuration. Vänta tills länkarna är gröna.

// STEP 02 — Kontrollera startläget

Öppna Desktop → Command Prompt. Testa alla sex par:

  • PC1–PC2
  • PC1–PC3
  • PC1–PC4
  • PC2–PC3
  • PC2–PC4
  • PC3–PC4

Kör exempelvis från PC1:

ping 192.168.1.240

Anteckna resultaten. Om första försöket tappar paket när ARP eller länken etableras, kör igen.

// STEP 03 — Dela nätet

Dela 192.168.1.0/24 i två lika stora nät. Behåll samtliga PC-adresser.

  1. Räkna ut den nya masken själv.
  2. Ange nätadress, hostintervall och broadcast för båda subnäten.
  3. Förutsäg vilka pingtester som lyckas efter ändringen.
  4. Ändra endast nätmasken på alla fyra PC. Lämna gateway tom.
  5. Gör om alla sex tester och jämför med din förutsägelse.

// STEP 04 — Följ ett misslyckat försök

Byt till Simulation. Visa bara ARP och ICMP med Edit Filters. Starta ett ping från PC1 till PC3 och stega med Capture/Forward. Jämför med ett ping från PC1 till PC2.

  1. Vad visar simulatorn när PC1 försöker nå det andra subnätet?
  2. Skickas någon ram till PC3? Dokumentera vad just din version visar.
  3. Varför kan switchen inte ensam få kommunikationen att fungera?
  4. Vad skulle behövas för att alla fyra ska kommunicera med /25?
  5. Har ni skapat två VLAN eller två broadcast-domäner genom att ändra masken?
Reveal discussion

Ny mask: 255.255.255.128, alltså /25.

  • Första nätet: 192.168.1.0/25. Hostar .1–.126. Broadcast .127.
  • Andra nätet: 192.168.1.128/25. Hostar .129–.254. Broadcast .255.

Med /24 lyckas alla par. Med /25 lyckas normalt PC1–PC2 och PC3–PC4. Övriga par behöver routing, som saknas.

För att behålla /25 och nå mellan näten behövs en router eller annan lager 3-enhet med anslutning till båda näten och rätt routes/gatewayinställningar.

Ett vanligt produktionsupplägg är ett VLAN per subnät och routing mellan dem.

Maskbytet ändrar datorernas IP-bedömning. Alla portar ligger fortfarande i samma VLAN och samma lager 2-broadcast-domän.
