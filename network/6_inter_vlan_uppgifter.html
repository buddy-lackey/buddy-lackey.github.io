// IPv4 & SUBNETTING
CHALLENGE 01 // NETWORK ID

Same subnet?

Tre datorer har följande IP-konfiguration:

HostIP-adressNätmask
PC-A192.168.1.10255.255.255.128
PC-B192.168.1.100255.255.255.128
PC-C192.168.1.200255.255.255.128

Vilka datorer tillhör samma IP-subnät? Vad är nätadressen för respektive dator?

Reveal discussion

Masken motsvarar /25. Den delar ett /24-nät i två delar:

192.168.1.0/25
192.168.1.128/25

PC-A och PC-B tillhör det första subnätet. PC-C tillhör det andra.

PC-C behöver routing för att kommunicera med PC-A eller PC-B på IP-nivå.

CHALLENGE 02 // BITWISE AND

Find the network

En dator har följande adress:

IP:      172.16.35.77
Mask:    255.255.252.0

Ta reda på:

  1. Vilken CIDR-prefixlängd motsvarar masken?
  2. Vilken är nätadressen?
  3. Vilken är broadcastadressen?
Reveal discussion 
255.255.252.0 = /22

Nätadress:
172.16.32.0/22

Broadcast:
172.16.35.255

Den tredje oktetten har blockstorleken 4. Subnäten börjar därför vid 0, 4, 8 ... 32, 36 och så vidare.

Adressen 172.16.35.77 tillhör intervallet 172.16.32.0–172.16.35.255.

// LAYER 2 VS LAYER 3
CHALLENGE 03 // VLAN ISOLATION

Same switch. No communication.

Två datorer är anslutna till samma fysiska switch.

PC-A                    PC-B
192.168.10.10           192.168.20.10
VLAN 10                 VLAN 20
      \                 /
       [ Layer 2 Switch ]

PC-A försöker pinga PC-B men får inget svar.

Varför kan inte switchen skicka trafiken direkt mellan datorerna?

Reveal discussion

Varje VLAN är en separat broadcastdomän på Layer 2. En vanlig Layer 2-switch vidarebefordrar inte Ethernet-frames mellan olika VLAN.

Eftersom datorerna dessutom ligger i olika IP-subnät behövs en Layer 3-enhet som kan routa trafiken.

CHALLENGE 04 // DEFAULT GATEWAY

Which MAC address?

PC-A vill skicka ett ICMP Echo Request till PC-B.

PC-A
IP:       192.168.10.10/24
Gateway:  192.168.10.1

PC-B
IP:       192.168.20.10/24

Vilken destinations-IP finns i IP-paketet?

Vilken destinations-MAC används i Ethernet-framen när PC-A skickar paketet?

Vilket protokoll kan PC-A använda för att hitta den MAC-adressen?

Reveal discussion

Destinations-IP är 192.168.20.10.

Destinations-MAC är MAC-adressen för nästa hopp, alltså PC-A:s default gateway.

PC-A använder ARP för att ta reda på gatewayens MAC-adress, om den inte redan finns i ARP-tabellen.

IP-destinationen förblir PC-B även om Ethernet-framen först skickas till routern.

// INTER-VLAN ARCHITECTURES
CHALLENGE 05 // ROUTER-ON-A-STICK

Something is missing

En tekniker har konfigurerat följande på en router:

interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

Datorerna kan fortfarande inte kommunicera mellan VLAN 10 och VLAN 20.

Nämn minst tre saker du skulle kontrollera innan du ändrar routerkonfigurationen.

Reveal discussion
  • Är switchporten mot routern konfigurerad som trunk?
  • Är VLAN 10 och VLAN 20 tillåtna på trunken?
  • Är det fysiska routerinterfacet aktiverat?
  • Är datorernas IP-adresser och gateway korrekta?
  • Är datorernas switchportar i rätt access-VLAN?

En korrekt subinterface-konfiguration räcker inte om resten av trafikvägen är felkonfigurerad.

CHALLENGE 06 // SVI

The missing command

En Layer 3-switch har följande konfiguration:

vlan 10
vlan 20

interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown

SVI-interfacen är up/up och datorerna har rätt gateway. Men switchen routar inte mellan VLAN.

Vilket centralt kommando saknas?

Reveal discussion 
ip routing

Kommandot aktiverar IPv4-routing på en Layer 3-switch som stöder funktionen.

Ett SVI är ett virtuellt Layer 3-interface kopplat till ett VLAN. Det kan fungera som default gateway för VLAN:ets datorer.

CHALLENGE 07 // DESIGN DECISION

Choose the architecture

Du ska föreslå en lösning för tre olika miljöer.

MiljöFörutsättningar
AStort campusnät med mycket intern trafik mellan VLAN
BMindre kontor där trafik mellan avdelningar ska filtreras
CEn enkel utbildningslabb med en router och en Layer 2-switch

Välj en lämplig metod för varje miljö och motivera.

Reveal discussion

A: Layer 3-switch med SVI är ett rimligt val för högpresterande intern routing.

B: Brandvägg med VLAN-interface kan vara lämplig när trafiken mellan VLAN behöver kontrolleras.

C: Router-on-a-stick är en enkel metod som demonstrerar trunking, subinterface och routing.

Det finns inte alltid ett enda rätt svar. Krav på kapacitet, säkerhet, kostnad och drift påverkar valet.

// FINAL CHALLENGE
BOSS // FIREWALL ROUTING

Route exists. Ping fails.

En brandvägg har två VLAN-interface:

VLAN 10: 192.168.10.1/24
VLAN 20: 192.168.20.1/24

PC-A: 192.168.10.10/24
PC-B: 192.168.20.10/24

Båda datorerna har korrekt default gateway. Brandväggen känner till båda direktanslutna subnäten.

Ändå misslyckas kommunikationen mellan datorerna.

Uppdrag: Förklara varför fungerande routing inte automatiskt innebär att trafiken tillåts.

Vilka kontroller skulle du göra på brandväggen?

Reveal discussion

Routingtabellen avgör vart trafiken ska skickas. Brandväggens säkerhetspolicyer avgör om trafiken får passera.

Kontrollera bland annat:

  • Att rätt interface och subnät används.
  • Att en policy tillåter önskad trafik.
  • Att policyn gäller rätt käll- och destinationszon.
  • Att ICMP tillåts om ping används som test.
  • Att datorernas egna brandväggar inte blockerar ICMP.

En viktig slutsats: Routbar betyder inte tillåten.
