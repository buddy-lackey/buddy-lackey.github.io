NETWORK LAB

ROUTING BETWEEN NETWORKS

● NETWORK ONLINE_

Två datorer befinner sig i olika IP-nät. Din uppgift är att konfigurera nätverket så att de kan kommunicera med varandra via en FortiGate 40F.

Målet är inte bara att få ett fungerande ping. Du ska kunna förklara varför paketet tar den väg det gör.

// NETWORK TOPOLOGY
PC1 FortiGate 40F PC2 192.168.1.10 [ ROUTER ] 192.168.2.10 | | | | | | | | Switch1 ---------------+ +--------------- Switch2 192.168.1.0/24 192.168.2.0/24
CHALLENGE 01

Two networks

Studera topologin.

PC1 har adressen: 

192.168.1.10/24

PC2 har adressen: 

192.168.2.10/24

Är PC1 och PC2 i samma IP-nät?

Kan PC1 skicka en Ethernet-frame direkt till PC2?

Reveal discussion

Nej. Med nätmask /24 tillhör PC1 nätet 192.168.1.0/24 och PC2 nätet 192.168.2.0/24.

PC1 behöver därför skicka paketet till en router som kan vidarebefordra det till det andra nätverket.

// CONFIGURATION
CHALLENGE 02

Configure the router

FortiGate 40F ska agera router mellan de två näten.

Konfigurera ett FortiGate-interface i varje nät.

Device Interface IP address
PC1 Ethernet 192.168.1.10/24
FortiGate Network 1 ?
FortiGate Network 2 ?
PC2 Ethernet 192.168.2.10/24

Vilka IP-adresser väljer du till FortiGate?

Hint: varje routerinterface måste ha en adress som tillhör det nätverk interfacet är anslutet till.

Reveal discussion

Ett enkelt val är: 

FortiGate Network 1: 192.168.1.1/24
FortiGate Network 2: 192.168.2.1/24

Det finns flera möjliga adresser, men interfacen måste ligga i respektive subnät och får inte använda en adress som redan används.

CHALLENGE 03

Test the local network

Innan du försöker nå det andra nätverket: testa först den lokala kommunikationen.

Från PC1:

ping 192.168.1.1

Från PC2:

ping 192.168.2.1

Varför behöver PC1 ingen router för att nå 192.168.1.1?

Reveal discussion

PC1 och FortiGate-interfacet 192.168.1.1 ligger i samma 192.168.1.0/24-nät.

Destinationen betraktas därför som direkt ansluten (on-link). PC1 kan använda ARP för att hitta MAC-adressen till FortiGate-interfacet och skicka Ethernet-ramen direkt dit.

// DEFAULT GATEWAY
CHALLENGE 04

Leave the local network

PC1 försöker nu nå: 

192.168.2.10

PC1 ser att destinationen inte ligger i det lokala 192.168.1.0/24-nätet.

Vart ska PC1 skicka paketet?

Konfigurera rätt default gateway på PC1 och PC2.

Device Default gateway
PC1 ?
PC2 ?

Testa därefter:

ping 192.168.2.10
Reveal discussion

PC1 använder FortiGate-interfacet i sitt eget nät som gateway: 192.168.1.1.

PC2 använder på motsvarande sätt 192.168.2.1.

Default gateway används när datorn behöver nå ett nätverk som inte kan nås via en mer specifik route.

// ROUTING TABLE
CHALLENGE 05

Ask the operating system

Kör följande på PC1: 

route print

Hitta routen för: 

192.168.1.0/24

Vad betyder On-link?

Kan du hitta default route?

Den visas normalt som: 

Network Destination    Netmask
0.0.0.0                0.0.0.0

Vilken route används när destinationen är 192.168.2.10?

Reveal discussion

192.168.1.0/24 är direkt anslutet och visas därför som on-link.

192.168.2.10 matchar inte det lokala nätet. Om ingen mer specifik route finns används default route, vilket skickar trafiken till PC1:s default gateway.

// ARP
CHALLENGE 06

Who gets the Ethernet frame?

Rensa eller studera ARP-tabellen och pinga sedan PC2. 

arp -a

ping 192.168.2.10

arp -a

Vilken MAC-adress behöver PC1 för att skicka paketet?

Behöver PC1 känna till PC2:s MAC-adress?

Reveal discussion

PC1 behöver MAC-adressen till nästa hop: FortiGate-interfacet 192.168.1.1.

PC2 befinner sig på ett annat Layer 2-nät. PC1 skickar därför inte Ethernet-ramen direkt till PC2.

PC1 känner till destinationens IP-adress, men Ethernet-ramens destination är FortiGatens MAC-adress.

// FOLLOW THE PACKET
CHALLENGE 07

IP packet vs Ethernet frame

PC1 skickar ett ICMP Echo Request till PC2.

IP SOURCE: 192.168.1.10
IP DESTINATION: 192.168.2.10

MAC SOURCE: ?
MAC DESTINATION: ?

Vilka MAC-adresser används när ramen går från PC1 till FortiGate?

FortiGate routar sedan paketet vidare på nät 2.

IP SOURCE: 192.168.1.10
IP DESTINATION: 192.168.2.10

MAC SOURCE: ?
MAC DESTINATION: ?

Vad händer med IP-adresserna?

Vad händer med MAC-adresserna?

Reveal discussion

IP-adresserna identifierar ändpunkterna och är i detta enkla routingexempel oförändrade.

Ethernet-ramen gäller däremot bara för den aktuella länken. När FortiGate vidarebefordrar paketet skapas därför en ny Ethernet-frame.

På nät 1 är destinationens MAC-adress FortiGatens MAC. På nät 2 är destinationens MAC-adress PC2:s MAC.

// BREAK IT
CHALLENGE 08

Remove the gateway

Ta bort default gateway från PC1.

Testa:

ping 192.168.1.1
ping 192.168.2.10

Vilken ping fungerar?

Förklara resultatet med hjälp av routingtabellen.

Reveal discussion

PC1 kan fortfarande nå 192.168.1.1 eftersom destinationen ligger i det direkt anslutna nätverket.

Men utan default gateway finns ingen route som talar om hur PC1 ska nå 192.168.2.0/24.

CHALLENGE 09

Wrong gateway

Konfigurera istället: 

Default gateway: 192.168.1.254

Anta att ingen sådan router finns.

Felsök problemet med: 

ipconfig
route print
arp -a
ping
tracert

Kan du avgöra var kommunikationen bryts?

Reveal discussion

Routingtabellen säger åt PC1 att använda 192.168.1.254 som nästa hop.

Eftersom gatewayen ligger i det lokala nätverket försöker PC1 först hitta dess MAC-adress med ARP.

Om ingen enhet har adressen 192.168.1.254 får PC1 inget användbart ARP-svar och kan därför inte ens leverera Ethernet-ramen till sin tänkta router.

// FINAL CHALLENGE
CHALLENGE 10

Explain the journey

PC1 skickar: 

ping 192.168.2.10

Förklara hela paketets väg från PC1 till PC2.

Använd minst följande begrepp:

subnet
routing table
default gateway
ARP
MAC address
Ethernet frame
IP packet
router

Var fattas routingbeslutet?

När används ARP?

Vilka adresser ändras när paketet passerar routern?

Reveal discussion

PC1 använder nätmasken för att avgöra att 192.168.2.10 inte ligger i det lokala nätverket.

Routingtabellen väljer därför default route och nästa hop blir FortiGate.

PC1 använder ARP för att hitta FortiGatens MAC-adress och placerar IP-paketet i en Ethernet-frame adresserad till routern.

FortiGate tar emot ramen, tar bort Layer 2-inkapslingen, undersöker destinationens IP-adress och gör ett nytt routingbeslut.

Eftersom 192.168.2.0/24 är direkt anslutet kan FortiGate använda ARP för att hitta PC2:s MAC-adress.

IP-paketet kapslas sedan in i en ny Ethernet-frame och skickas till PC2.
