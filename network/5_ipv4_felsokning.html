LECTURE 05 // IPv4

IP-detektiven: samma nät eller gateway?

● NETWORK ONLINE_

Cirka 25–35 minuter · Arbeta ensam eller i par

Anta samma VLAN, en vanlig lager 2-switch, inga extra routes och inga blockerande brandväggsregler. Gateway saknas om inget annat anges.

// CHALLENGE 01 — Vem kan prata direkt?

DatorIPv4-adress
A192.168.10.10/26
B192.168.10.62/26
C192.168.10.65/26
D192.168.10.100/26
  1. Vilka par kan normalt pinga varandra direkt?
  2. Vilken nätadress och broadcastadress hör till varje dator?
  3. Vad gör A när du försöker pinga C utan gateway?
  4. Varför löser inte switchens MAC-tabell problemet?
Reveal discussion

A och B tillhör 192.168.10.0/26, med broadcast 192.168.10.63. C och D tillhör 192.168.10.64/26, med broadcast 192.168.10.127. A–B och C–D kan kommunicera direkt.

A saknar route till C:s nät och skickar normalt inget direkt ARP-anrop efter C. Switchen kan vidarebefordra ramar, men datorns routingbeslut avgör nästa hopp.

Olika IP-subnät på samma VLAN är ingen säkerhetsisolering. Särskilda routes kan ändra datorernas beteende.

// CHALLENGE 02 — Den luriga nätmasken

Dator A: 192.168.1.10/24
Dator B: 192.168.1.200/25

Samma switch och samma VLAN.
Ingen gateway på någon dator.
  1. Vilket nät anser A att den tillhör? Och B?
  2. Anser A att B är lokal? Anser B att A är lokal?
  3. Kan ett komplett pingutbyte normalt lyckas? Förklara båda riktningarna.
  4. Ge en korrigering som låter dem kommunicera direkt.
Reveal discussion

A tillhör 192.168.1.0/24 och ser B som lokal.

B tillhör 192.168.1.128/25 och ser A som extern.

A kan normalt skicka förfrågan direkt, men B saknar route för svaret. Pingutbytet misslyckas.

Ge båda /24 om det är det avsedda gemensamma subnätet. Med B:s /25-mask hamnar .10 och .200 på olika sidor av gränsen.

// CHALLENGE 03 — Vem får ramen?

Dator A
IP:  192.168.10.10/26
MAC: 02:00:00:00:00:10

Dator B
IP:  192.168.10.20/26
MAC: 02:00:00:00:00:20

Default gateway
IP:  192.168.10.1
MAC: 02:00:00:00:00:01
  1. A pingar B. Ange destination-IP och destination-MAC i Echo Request-ramen efter ARP.
  2. A pingar 8.8.8.8. Ange samma fält på länken från A till gatewayen.
  3. Vems MAC-adress efterfrågar A med ARP i respektive fall?
Reveal discussion

Till B:

Destination-IP:  192.168.10.20
Destination-MAC: 02:00:00:00:00:20

Till Internet, på den lokala länken:

Destination-IP:  8.8.8.8
Destination-MAC: 02:00:00:00:00:01

ARP används för att hitta B:s respektive gatewayens MAC-adress. Datorn behöver inte känna till internetserverns MAC-adress.

Uppgiften gäller unicast-ramarna efter ARP, inte själva ARP-broadcasten.
