Från ARP till HTTP

Mål: Se ARP, ICMP, Ethernet, IP, TCP och HTTP i Simulation Mode.

PC1     192.168.1.10/24
PC2     192.168.1.20/24
Server  192.168.1.100/24
BYGG OCH TESTA
  1. Skapa topologin och konfigurera adresserna.
  2. Aktivera HTTP på servern.
  3. Kontrollera PC1:s ARP-cache med arp -a.
  4. Gå till Simulation Mode och pinga PC2.
  5. Identifiera ARP Request, ARP Reply, ICMP Echo Request och ICMP Echo Reply.
  6. Kör arp -a igen. Vad har förändrats?
  7. Öppna http://192.168.1.100 från PC1.
  8. Expandera informationen för Ethernet, IP, TCP och HTTP i simuleringen.

REVEAL DISCUSSION

ARP översätter den lokalt relevanta IPv4-adressen till en MAC-adress. HTTP-trafiken kapslas i TCP, därefter IP och slutligen Ethernet innan den överförs.
