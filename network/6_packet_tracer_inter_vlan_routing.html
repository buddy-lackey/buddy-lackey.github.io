Inter-VLAN Routing

Fyra metoder. Samma mål: låt datorer i olika VLAN kommunicera och förstå vilken enhet som routar trafiken.

● NETWORK LAB ONLINE_
// MISSION BRIEF

Bygg nätet steg för steg

Utgå från en Layer 2-switch (t.ex. Cisco 2960), två PC och två VLAN. Behåll gärna samma IP-plan när du byter routingmetod.

PC1PC2
VLAN1020
IP192.168.10.10/24192.168.20.10/24
Gateway192.168.10.1192.168.20.1

Skapa VLAN 10 och 20 på switchen och anslut datorerna till var sin accessport. Testa ping innan routing finns: vad händer?

CHALLENGE 01 · LEGACY

One physical interface per VLAN

Använd en router med två Ethernet-interface. Anslut ett interface till en accessport i VLAN 10 och det andra till en accessport i VLAN 20. Ge routern gateway-adresserna i tabellen.

  1. Skapa två separata fysiska förbindelser mellan router och switch.
  2. Konfigurera routerinterface med rätt IP-adresser.
  3. Testa ping mellan PC1 och PC2.
Reveal discussion

Varje VLAN har en egen fysisk anslutning till routern. Trafiken passerar en Layer 3-enhet när den ska mellan olika IP-subnät. Ingen trunk krävs.

CHALLENGE 02 · ROUTER-ON-A-STICK

One trunk, multiple VLANs

Byt till en enda kabel mellan routern och switchen. Konfigurera switchporten som 802.1Q-trunk och skapa ett subinterface per VLAN på routern.

! Exempel på router med GigabitEthernet0/0
interface GigabitEthernet0/0
 no shutdown
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

Anpassa interfacenamnen efter routern du använder.

Reveal discussion

Trunken transporterar flera VLAN över en fysisk kabel. Subinterfacen routar mellan IP-subnäten. 802.1Q-taggar identifierar VLAN på trunken.

CHALLENGE 03 · LAYER 3 SWITCH

Route with SVIs

Byt routern mot en Layer 3-switch, exempelvis Cisco 3560. Skapa ett SVI per VLAN och aktivera IP-routing.

ip routing
interface Vlan10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface Vlan20
 ip address 192.168.20.1 255.255.255.0
 no shutdown

Kontrollera att VLAN finns och att minst en aktiv port tillhör respektive VLAN. Testa ping.

Reveal discussion

Layer 3-switchen routar mellan VLAN via sina virtuella VLAN-interface (SVI). Ingen separat router behövs.

// IMPORTANT · PACKET TRACER LIMITATION

ASA 5506-X: inte router-on-a-stick i vår simulator

I den Packet Tracer-version vi använder avvisar ASA 5506-X kommandot interface GigabitEthernet1/1.10. Det innebär att vi inte kan genomföra ASA-delen med 802.1Q-subinterface i just denna simulator.

Det är inte en generell begränsning i den verkliga ASA 5506-X, som har stöd för VLAN-subinterface. I Packet Tracer-labben använder vi i stället två fysiska ASA-interface, ett per VLAN.

CHALLENGE 04 · BOSS LEVEL · CISCO ASA 5506-X

Inter-VLAN routing with a firewall

Nu ersätter du routern med en ASA 5506-X. Använd GigabitEthernet1/1 för VLAN 10 och GigabitEthernet1/2 för VLAN 20. Det kräver två kablar till switchen, inte en trunk.

PC1 -- access VLAN 10 -- Cisco 2960 -- access VLAN 10 -- G1/1 ASA
PC2 -- access VLAN 20 -- Cisco 2960 -- access VLAN 20 -- G1/2 ASA

Switch – två accessportar mot ASA

vlan 10
vlan 20
interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10
interface GigabitEthernet0/2
 switchport mode access
 switchport access vlan 20

Byt portnummer om du har anslutit kablarna annorlunda. PC-portarna ska också ligga i respektive VLAN.

ASA – routade fysiska interface

enable
configure terminal
interface GigabitEthernet1/1
 nameif VLAN10
 security-level 100
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface GigabitEthernet1/2
 nameif VLAN20
 security-level 100
 ip address 192.168.20.1 255.255.255.0
 no shutdown
same-security-traffic permit inter-interface

Uppdrag: Kontrollera interface-status och routing. Pinga från PC1 till PC2. Om ping inte fungerar, felsök systematiskt: VLAN, gateway, ASA-policy och ICMP-inspektion. Beroende på simulatorns beteende kan ytterligare ICMP-regler eller inspektion behövas.

Fundera: Vad skiljer ASA-lösningen från legacy-routing med en vanlig router, trots att båda använder två fysiska kablar?

Reveal discussion

Den fysiska topologin liknar legacy-routing, men ASA är en stateful brandvägg som kan tillämpa säkerhetspolicy mellan näten. Kommandot same-security-traffic permit inter-interface tillåter trafik mellan interface med samma security level, men ersätter inte felsökning av andra policyer och ICMP-beteende. I en riktig ASA 5506-X kan man även använda VLAN-subinterface på en trunk.

CHALLENGE 05 · COMPARE

Four solutions, one problem

  1. Vilka metoder kräver flera kablar till routing-enheten?
  2. Vilka metoder använder 802.1Q?
  3. Vilken enhet är default gateway i respektive lösning?
  4. Var kan du tillämpa stateful brandväggsregler?
  5. Varför fungerar inte ping mellan VLAN utan routing?
Reveal discussion

Legacy och vår ASA-labb använder en fysisk kabel per VLAN. Router-on-a-stick använder 802.1Q-trunk; en Layer 3-switch använder SVI. ASA kan filtrera trafik statefully. VLAN separerar Layer 2-domäner och olika IP-subnät kräver Layer 3-routing för att kommunicera.
