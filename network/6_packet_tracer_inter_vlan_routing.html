Inter-VLAN Routing

Fyra metoder. Samma mål: låt datorer i olika VLAN kommunicera och förstå vilken enhet som routar trafiken.

● NETWORK LAB ONLINE_
// MISSION BRIEF

Bygg nätet steg för steg

Utgå från en Layer 2-switch (t.ex. Cisco 2960), två PC och två VLAN. Behåll gärna samma IP-plan när du byter routingmetod.

PC1PC2
VLAN1020
IP192.168.10.10/24192.168.20.10/24
Gateway192.168.10.1192.168.20.1

Skapa VLAN 10 och 20 på switchen och anslut datorerna till var sin accessport. Testa ping innan routing finns: vad händer?

CHALLENGE 01 · LEGACY

One physical interface per VLAN

Använd en router med två Ethernet-interface. Anslut ett interface till en accessport i VLAN 10 och det andra till en accessport i VLAN 20. Ge routern gateway-adresserna i tabellen.

  1. Skapa två separata fysiska förbindelser mellan router och switch.
  2. Konfigurera routerinterface med rätt IP-adresser.
  3. Testa ping mellan PC1 och PC2.
Reveal discussion

Varje VLAN har en egen fysisk anslutning till routern. Trafiken passerar en Layer 3-enhet när den ska mellan olika IP-subnät. Ingen trunk krävs.

CHALLENGE 02 · ROUTER-ON-A-STICK

One trunk, multiple VLANs

Byt till en enda kabel mellan routern och switchen. Konfigurera switchporten som 802.1Q-trunk och skapa ett subinterface per VLAN på routern.

! Exempel på router med GigabitEthernet0/0
interface GigabitEthernet0/0
 no shutdown
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

Anpassa interfacenamnen efter routern du använder.

Reveal discussion

Trunken transporterar flera VLAN över en fysisk kabel. Subinterfacen routar mellan IP-subnäten. 802.1Q-taggar identifierar VLAN på trunken.

CHALLENGE 03 · LAYER 3 SWITCH

Route with SVIs

Byt routern mot en Layer 3-switch, exempelvis Cisco 3560. Skapa ett SVI per VLAN och aktivera IP-routing.

ip routing
interface Vlan10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface Vlan20
 ip address 192.168.20.1 255.255.255.0
 no shutdown

Kontrollera att VLAN finns och att minst en aktiv port tillhör respektive VLAN. Testa ping.

Reveal discussion

Layer 3-switchen routar mellan VLAN via sina virtuella VLAN-interface (SVI). Ingen separat router behövs.

// IMPORTANT · PACKET TRACER LIMITATION

ASA 5506-X: inte router-on-a-stick i vår simulator

I den Packet Tracer-version vi använder avvisar ASA 5506-X kommandot interface GigabitEthernet1/1.10. Det innebär att vi inte kan genomföra ASA-delen med 802.1Q-subinterface i just denna simulator.

Detta är en begränsning i den simulatorversion som testades, inte ett bevis för hur all verklig ASA-hårdvara fungerar. Här använder vi två fysiska ASA-interface med var sin accessport på switchen.

CHALLENGE 04 · BOSS LEVEL · CISCO ASA 5506-X

Inter-VLAN routing with a firewall

Byt ut routern mot en ASA 5506-X. Bygg med en fysisk ASA-port per VLAN. Använd inte trunk eller subinterface i den här Packet Tracer-övningen.

PC1 (VLAN 10) -- Fa0/1   Cisco 2960   Fa0/22 -- G1/1 ASA
PC2 (VLAN 20) -- Fa0/2                Fa0/23 -- G1/2 ASA

Steg 1 · Switch

Skapa VLAN 10 och 20. Lägg PC-portarna och motsvarande ASA-portar i rätt VLAN som accessportar. Exempel:

enable
configure terminal
vlan 10
vlan 20
interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10
interface FastEthernet0/22
 switchport mode access
 switchport access vlan 10
interface FastEthernet0/2
 switchport mode access
 switchport access vlan 20
interface FastEthernet0/23
 switchport mode access
 switchport access vlan 20
end

Steg 2 · ASA

Konfigurera två routade interface med olika security levels. VLAN10 är mer betrott än VLAN20 i den här övningen.

enable
configure terminal
interface GigabitEthernet1/1
 nameif VLAN10
 security-level 100
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface GigabitEthernet1/2
 nameif VLAN20
 security-level 50
 ip address 192.168.20.1 255.255.255.0
 no shutdown
end

Uppdrag: Pinga från PC1 till PC2. Förklara hur trafiken färdas via switchen och brandväggen. Testa sedan om kommunikationen fungerar även när den initieras från PC2. Varför kan resultatet skilja sig?

Ledtråd 1 · Kontrollera kablar och VLAN

På switchen: show vlan brief och show mac address-table. PC1 och ASA G1/1 ska finnas i VLAN10, PC2 och ASA G1/2 i VLAN20. En switch vidarebefordrar inte en ram direkt mellan VLAN.

Ledtråd 2 · Kontrollera IP och routing

Kontrollera IP, nätmask och default gateway på båda datorerna. På ASA: show running-config interface GigabitEthernet1/1, show running-config interface GigabitEthernet1/2 och show route. Routingtabellen bör visa 192.168.10.0/24 via G1/1 och 192.168.20.0/24 via G1/2.

Ledtråd 3 · Felsök i Simulation Mode

Filtrera på ARP och ICMP. Skicka en Simple PDU från PC1 till PC2. Följ Echo Request och Echo Reply separat. Kontrollera särskilt vilket ASA-interface returtrafiken lämnar. Om switchen floodar en ram med PC1:s MAC i VLAN20 är det ett symptom på att ramen finns i fel VLAN — flytta inte PC1 till VLAN20 som en genväg.

Ledtråd 4 · Brandväggspolicy och ICMP

En ASA har stateful filtrering och security levels. Trafik från högre till lägre security level behandlas annorlunda än trafik som initieras från lägre till högre. Om routingen ser korrekt ut men ping inte fungerar, undersök ACL och eventuell ICMP-inspektion. Börja inte med att öppna permit ip any any på alla interface. Tänk också på att ping till ASA:s eget interface och ping genom ASA är olika tester.

Lärarens facit · Vad behövdes?

I den testade Packet Tracer-topologin fungerade PC1 → PC2 med två separata ASA-interface, olika security levels och nätverken 192.168.10.0/24 respektive 192.168.20.0/24. Kommandot same-security-traffic permit inter-interface avvisades av simulatorn och behövs inte i denna konfiguration. Vi behövde inte heller trunk, ASA-subinterface eller någon statisk route mellan de direktanslutna näten. De tidigare angränsande 192.168.1.0/25 och 192.168.1.128/25 gav i vår testmiljö en märklig routingtabell och felaktig returväg; grundorsaken fastställdes inte. Exakt vilka ACL- och ICMP-inställningar som behövs för andra trafikflöden måste testas separat.

CHALLENGE 05 · COMPARE

Four solutions, one problem

  1. Vilka metoder kräver flera kablar till routing-enheten?
  2. Vilka metoder använder 802.1Q?
  3. Vilken enhet är default gateway i respektive lösning?
  4. Var kan du tillämpa stateful brandväggsregler?
  5. Varför fungerar inte ping mellan VLAN utan routing?
Reveal discussion

Legacy och vår ASA-labb använder en fysisk kabel per VLAN. Router-on-a-stick använder 802.1Q-trunk; en Layer 3-switch använder SVI. ASA kan filtrera trafik statefully. VLAN separerar Layer 2-domäner och olika IP-subnät kräver Layer 3-routing för att kommunicera.
