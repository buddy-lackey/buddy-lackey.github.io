// NAT BASICS
CHALLENGE 01

Vem byter adress?

En dator 192.168.5.20 besöker 203.0.113.10:443. Routerns publika adress är 198.51.100.8.

Vilken IP-adress ser webbservern som avsändare? Vilken enhet utför översättningen?

Reveal discussion

Vid vanlig utgående SNAT ser webbservern 198.51.100.8. NAT-routern ändrar källadressen. Svaren skickas tillbaka via routerns översättningstabell.

CHALLENGE 02

Två klienter, en publik IP

192.168.5.20:51000 → 203.0.113.10:443
192.168.5.21:51000 → 203.0.113.10:443

Publik IP: 198.51.100.8

Hur kan båda klienterna få rätt svar trots att de använder samma källport?

Reveal discussion

Med PAT kan routern översätta till olika publika källportar, exempelvis 198.51.100.8:40001 och :40002. Routern håller reda på respektive flöde. Exakta portar bestäms av NAT-implementationen.

CHALLENGE 03

Port forwarding eller magi?

Du vill nå en kamera på 192.168.5.30:8080 utifrån. Routern har publik IP 198.51.100.8.

Beskriv en möjlig DNAT-regel. Varför krävs även korrekt brandväggspolicy?

Reveal discussion

Exempel: inkommande TCP till 198.51.100.8:8443 översätts till 192.168.5.30:8080. DNAT ändrar destinationen, men brandväggen måste också tillåta trafiken.

CHALLENGE 04

CG-NAT-fällan

Klient:     192.168.5.20
Egen WAN:   100.72.14.9
Publik IP:  198.51.100.42

Varför räcker det inte med port forwarding i hemroutern för inkommande anslutningar från internet?

Reveal discussion

Adressen 100.72.14.9 ligger i 100.64.0.0/10, som används för delad adressrymd hos operatörer. Trafiken passerar även operatörens NAT. Hemroutern kan inte själv konfigurera inkommande översättning i operatörens utrustning.

// WIRESHARK LAB
BOSS-SHARK

Kan du verkligen se NAT?

Arbeta i ett nät där din dator använder en router med NAT. Starta Wireshark på datorns aktiva interface. Besök en valfri HTTPS-webbplats.

Filtrera med din egen IPv4-adress:

ip.addr == 192.168.5.20

Byt ut adressen mot din dators faktiska IP. Använd tcp eller tcp.port == 443 om anslutningen använder TCP. Webbläsare kan även använda QUIC/UDP.

  1. Hitta ett utgående paket. Ange IP-adresser och portar.
  2. Ser du privat eller publik källadress?
  3. Kan du bevisa NAT-översättningen från denna fångst?
  4. Vad behöver du undersöka för att verifiera NAT?

BOSS QUESTION: Är NAT samma sak som en brandvägg?

Reveal discussion

På klientens interface ser du normalt den privata källadressen före NAT. En ensam klientfångst visar inte routerns omskrivning. Jämför med WAN-fångst, NAT-tabell eller observation från extern server. NAT är adress-/portöversättning, inte i sig en brandvägg.
