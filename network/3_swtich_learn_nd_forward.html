LEARN & FORWARD

Du är switchen. För varje frame måste du först lära från source och därefter fatta forwardingbeslut från destination.

MÅL
Bygg en MAC-tabell steg för steg och förutsäg forwarding, flooding och förändringar när en host flyttar.
TOPOLOGI
PC-A -- P1 ┐
PC-B -- P2 ├── [ SW1 ]
PC-C -- P3 ┤
PC-D -- P4 ┘

A = 00:08:A2:AA:AA:01
B = 3C:52:82:BB:BB:02
C = 70:3A:CB:CC:CC:03
D = A4:5E:60:DD:DD:04

MAC TABLE: EMPTY
RULE: LEARN FROM SOURCE → FORWARD ON DESTINATION

Frame 1 — A → B

CHALLENGE 1

A skickar till B. Tabellen är tom.

  1. Vilken post lär SW1?
  2. Är B known eller unknown?
  3. Vilka portar får framen?
REVEAL
Learn: A → P1
B: unknown
Forward: flood → P2, P3, P4

Den inkommande porten P1 används inte för att skicka tillbaka samma floodade frame.

Frame 2 — B → A

CHALLENGE 2

B svarar från P2. Skriv hela tabellen efter learning-steget och välj sedan utgående port.

REVEAL
MAC TABLE
A → P1
B → P2

Destination A is known → forward only P1

Frame 3 — C → A

CHALLENGE 3

C skickar till A. Flood eller filtrerad unicast? Hur ser tabellen ut efteråt?

REVEAL
A → P1
B → P2
C → P3

A known → only P1

Frame 4 — D → C

CHALLENGE 4

D skickar till C. Beskriv learning och forwarding separat.

REVEAL

Först lär switchen D → P4 från source. Därefter slår den upp destination C, som redan finns på P3, och skickar framen endast dit.

Frame 5 — broadcast

Source:      A4:5E:60:DD:DD:04
Destination: FF:FF:FF:FF:FF:FF
Incoming:    P4
CHALLENGE 5
  1. Lär switchen fortfarande från source?
  2. Vilka portar får broadcasten?
  3. Lägger switchen in FF:FF:FF:FF:FF:FF som en vanlig destination i den dynamiska MAC-tabellen?
REVEAL

Source learning gäller fortfarande: D hör till P4. Broadcast floodas ut på P1, P2 och P3. Broadcastadressen behandlas inte som en vanlig dynamiskt inlärd hostdestination.

Frame 6 — host moved

PC-C kopplas ur P3 och ansluts till P5. C skickar därefter en frame.

CHALLENGE 6

Vad bör hända med posten för C?

REVEAL

När samma source MAC observeras på P5 uppdateras associationen så att C pekar på den aktuella porten.

C → P5

FINAL

Återskapa tabellen efter hela sekvensen utan att öppna tidigare svar.

REVEAL FINAL
A → P1
B → P2
C → P5
D → P4
