BAALSTORM // PARROT OS CLAMAV MINI LAB
$ ./clamav-lab --start

SCAN. DETECT. INTERPRET.

I den här labben installerar du ClamAV i Parrot OS, uppdaterar signaturdatabasen och testar antiviruset mot både en vanlig fil och EICAR-testfilen.

Du behöver ingen färdig labbmapp eller nedladdade övningsfiler. Allt skapas direkt i din Parrot-maskin.

VIKTIGT

Använd endast EICAR som testfil. EICAR är en ofarlig antivirus-testfil som är skapad för att utlösa antivirusdetektion utan att använda riktig skadlig kod.

00 // INSTALLERA CLAMAV

BASIC 10p

Öppna Terminal i Parrot OS.

Uppdatera först informationen om tillgängliga paket:

sudo apt update

Installera sedan ClamAV och FreshClam-tjänsten:

sudo apt install clamav clamav-daemon -y

Kontrollera installationen:

clamscan --version

01 // SIGNATURER

BASIC 10p

ClamAV använder bland annat signaturer för att identifiera kända hot.

Kontrollera FreshClam-tjänsten:

systemctl status clamav-freshclam

Om tjänsten redan körs är det normalt. Den ansvarar för att uppdatera antivirusets definitionsdatabas.

Du kan även försöka köra:

sudo freshclam
Om du får ett meddelande om att databasen är låst eller används av FreshClam-tjänsten betyder det ofta att den automatiska uppdateringstjänsten redan kör.

02 // SKAPA EN REN TESTFIL

BASIC 10p

Skapa en egen liten labbkatalog:

mkdir ~/clamav-lab cd ~/clamav-lab

Skapa en vanlig textfil:

echo "Baalstorm clean test file" > clean.txt

Kontrollera filen:

cat clean.txt

Scanna den:

clamscan clean.txt

Du bör få ett resultat ungefär som:

clean.txt: OK

03 // HÄMTA EICAR

INTERMEDIATE 15p

Öppna webbläsaren i Parrot OS.

Gå till EICAR:s officiella testsida:

https://www.eicar.org/download-anti-malware-testfile/

Ladda ner en av de vanliga EICAR-testfilerna.

Filnamnet kan exempelvis vara:

eicar.com
eller
eicar.com.txt

Kontrollera dina nedladdningar:

ls ~/Downloads

04 // SCANNA EICAR

INTERMEDIATE 20p

Scanna EICAR-filen.

Exempel:

clamscan ~/Downloads/eicar.com.txt

Använd det faktiska filnamnet om din fil heter något annat.

Vid lyckad detektion bör du få något som innehåller:

FOUND

Och sammanfattningen bör visa:

06 // REKURSIV SCAN

INTERMEDIATE 15p

ClamAV kan även skanna hela kataloger.

Testa:

clamscan -r ~/clamav-lab

Parametern:

-r

betyder att ClamAV går igenom katalogen rekursivt.

Testa även:

clamscan -r --infected ~/clamav-lab
FRÅGA

Vad gör parametern:
--infected

07 // SIGNATURBASERAD DETEKTERING

CONCEPT 20p
FILE | v CLAMAV | v KNOWN SIGNATURES | +---- MATCH ----> FOUND | +---- NO MATCH -> OK

EICAR är inte ett riktigt virus, men antivirusprogram känner igen dess testmönster.

FRÅGA

Rätt svar är:

Ett antivirusresultat med Infected files: 0 betyder att ClamAV inte hittade något som matchade dess detektion.

Det bevisar inte att filen är ofarlig.

Det är därför säkerhetsarbete ofta kombinerar flera lager, exempelvis antivirus, beteendeanalys, EDR, loggning och nätverksövervakning.
