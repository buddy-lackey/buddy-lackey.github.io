02 // AVALANCHE

HASH 15p
FILE A: salary=1000 FILE B: salary=1001

Hur bör SHA-256-hasharna för dessa filer förhålla sig?

De bör vara mycket olika trots att indatan bara skiljer sig lite. Det är avalanche-effekten.

03 // FILE TAMPERING

INTEGRITY 15p
ORIGINAL: report.pdf SHA256: AAA111... RECEIVED: report.pdf SHA256: E9B882...

Vad kan vi säga?

Filen är inte identisk med originalet. Något har förändrats.

Hashen säger däremot inte automatiskt vem som gjorde förändringen eller vem som skickade filen.
