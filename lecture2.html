Lecture 02

ONLINE THREATS & ATTACK SURFACE

The Internet is a shared environment. Systems are reachable by legitimate users, but also visible to scanners, opportunistic attackers, criminal groups, activists and state-backed actors. Security starts with understanding what is exposed, who may be interested in it, and how weaknesses can be exploited.

THREAT Something capable of causing harm to an asset.
VULNERABILITY A weakness that can be used or triggered.
EXPLOIT A method or technique used to take advantage of a vulnerability.
// THE INTERNET IS A SHARED MEDIUM
CHALLENGE 01

Who else can see the server?

A company publishes a new web server to the Internet. Employees use it for normal business, but within minutes it receives connection attempts from many unrelated IP addresses.

Why can this happen even if nobody has advertised the server?

Think about scanning, shared infrastructure and automated discovery.

Reveal discussion
Internet-facing services are exposed to a shared global network. Automated scanners continuously search address ranges and ports. A system does not need to be publicly advertised to be discovered.
// TERMS: THREAT, ACTOR, VULNERABILITY, EXPLOIT
CHALLENGE 02

Put the terms in the right place

A criminal group discovers an unpatched remote-code-execution flaw in a public-facing VPN appliance. They use exploit code to gain access to the internal network.
Threat actor = ?
Vulnerability = ?
Exploit = ?
Asset = ?
Reveal discussion
Threat actor: the criminal group.
Vulnerability: the unpatched RCE flaw.
Exploit: the code or technique used to trigger the flaw.
Asset: the VPN appliance, credentials, internal systems and data.
CHALLENGE 03

Zero-day or not?

A vulnerability is actively exploited in the wild before the vendor has released a patch.

Why is this especially difficult to defend against?

Bonus: does “zero-day” necessarily mean the vulnerability was discovered today?

Reveal discussion
A zero-day is dangerous because defenders may not yet have a patch or mature detection rules. The term generally refers to a vulnerability or exploit for which defenders had no effective patch available at the time of exploitation. It does not literally mean the flaw was created that day.

Reveal discussion

Manufacturers may prioritize production availability, OT systems and intellectual property. News organisations may prioritize publishing availability, source confidentiality and content integrity.
// ATTACK SURFACE
CHALLENGE 06

Find the attack surface

An organisation has:

• a public web server
• VPN access
• employee laptops
• cloud storage
• email
• remote administration
• third-party suppliers
• unused services still enabled

Which of these contribute to the attack surface?

Bonus: what could the organisation remove or reduce?

Reveal discussion
All of them can contribute to the attack surface. Attack surface includes exposed services, identities, applications, endpoints, third-party connections and unnecessary functionality. Reducing unused services, excessive permissions and unnecessary exposure can reduce the attack surface.
// COMMON ATTACKS & CIA
CHALLENGE 07

Which security property is affected?

DDoS makes a public service unreachable.

CIA = ?
Ransomware encrypts the file server.

CIA = ?
An attacker steals customer records.

CIA = ?
An attacker modifies financial records.

CIA = ?

Can one attack affect several CIA properties at the same time?

Reveal discussion
DDoS primarily affects Availability. Data theft affects Confidentiality. Unauthorized modification affects Integrity. Ransomware commonly affects Availability and may also affect Integrity and Confidentiality if attackers alter or exfiltrate data.
// APPLY THE SECURITY PRINCIPLES
CHALLENGE 08

Reduce the blast radius

An employee account is compromised through phishing. The account can access file shares, remote administration, development systems and several production servers.

Which security principles could have reduced the impact?

Consider: Least Privilege, Defense in Depth, Zero Trust, Segmentation, Secure by Default

Reveal discussion
Least Privilege could reduce account permissions. Segmentation could limit lateral movement. Zero Trust principles could require stronger verification for sensitive access. Defense in Depth could add additional controls. Secure by Default could reduce unnecessary access and services.
CHALLENGE 09

The unknown service

$ external-scan target.example

22/tcp    open   ssh
80/tcp    open   http
443/tcp   open   https
8080/tcp  open   unknown-admin-service
3389/tcp  open   rdp

What questions should a defender ask after seeing this?

Think about necessity, exposure, authentication, patching and attack surface.

Reveal discussion
Are all services required? Should RDP be Internet-facing? What is running on 8080? Are services patched? Is strong authentication enabled? Can network access be restricted? Any unnecessary exposed service increases attack surface.
