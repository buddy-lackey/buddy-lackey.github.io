05 // WHAT CAN EVE DO?

YES / NO

Ja, Eve kan räkna ut samma hash.

En vanlig SHA-256-hash är inte en hemlighet. Den kräver ingen nyckel.

Hashens uppgift här är att upptäcka förändring, inte att dölja information.

11 // BREAK THE SIGNATURE

TAMPERING 20p

Ändra nu ett tecken i evidence.txt.

Kör exakt samma verifiering igen:

openssl dgst -sha256 \ -verify baalstorm-public.pem \ -signature evidence.txt.sig \ evidence.txt

Vad händer?

________________________________________ ________________________________________

Verifieringen ska misslyckas.

Signaturen skapades för originalfilens hash. När filen ändras får den en annan hash och signaturen matchar därför inte längre.

12 // CAN EVE FORGE IT?

EVE 15p
EVE HAS: ✓ evidence.txt ✓ evidence.txt.sig ✓ baalstorm-public.pem ✓ all network traffic ✗ private key

Kan Eve skapa en ny giltig signatur för en modifierad fil?

Inte utan den privata signeringsnyckeln.

Den publika nyckeln är avsedd för verifiering, inte för att skapa Baalstorms signaturer.

13 // MALLORY TRIES AGAIN

MALLORY 25p

Mallory kontrollerar nu webbservern.

MALLORY CAN REPLACE: ✓ evidence.txt ✓ displayed SHA-256 ✓ evidence.txt.sig MALLORY DOES NOT HAVE: ✗ Baalstorm private key

Kan Mallory skapa en ny signatur som verifieras med Baalstorms riktiga publika nyckel?

Nej.

Hon kan byta fil och hash, men hon kan inte skapa en giltig Baalstorm-signatur utan Baalstorms privata nyckel.

Vad är problemet nu?

________________________________________ ________________________________________ ________________________________________

Bob vet inte automatiskt att den publika nyckeln verkligen tillhör Baalstorm.

En digital signatur är bara så användbar som vår tillit till den publika nyckel vi verifierar med.
