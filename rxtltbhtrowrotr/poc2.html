Reflected XSS PoC — Keycloak OIDC Endpoint

Target: idp.pt.2c8.com (Keycloak realm 2c8)

Parameter: scope

The payload is reflected unmodified in a text/html error page with no Content-Security-Policy header.

Click to trigger:

Run XSS PoC (alert box)

Expected result:

A JavaScript alert box showing idp.pt.2c8.com, proving script execution in the IDP's origin.

Impact:

XSS on idp.pt.2c8.com executes in the Keycloak IDP origin.
An attacker can:
- Steal Keycloak session cookies (AUTH_SESSION_ID)
- Access the idp-web API as the victim (same-origin)
- Redirect the OIDC flow to capture authorization codes
- Phish credentials by injecting a fake login form

Note:

The scanner noted a redirect occurs between the attack request and the response. The browser follows this redirect automatically. If the alert does not appear, the redirect may have changed — check the final response in DevTools (F12 → Network tab).
