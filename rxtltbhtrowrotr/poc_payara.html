Payara DAS Admin Access via nginx Path Traversal

PoC — WSTG-CONF-05 / CWE-668 — Semicolon path-parameter traversal bypasses nginx routing

Vulnerability: nginx treats ..; as part of the path segment (opaque), but Payara/GlassFish strips the ;... path parameter and resolves .. as directory traversal. This allows requests routed through /portal/api/v2/ on nginx to escape to arbitrary Payara back-end paths such as /management/domain (REST admin API) and /__asadmin/ (CLI interface).
