00 // CLOUD DOES NOT MEAN "NOT MY PROBLEM"

När en organisation flyttar system till molnet försvinner inte säkerhetsansvaret.

Ansvaret delas mellan:

CLOUD PROVIDER + CUSTOMER

Det brukar kallas:

SHARED RESPONSIBILITY MODEL

En enkel mental modell är:

CLOUD PROVIDER Security OF the cloud Datacenter Fysisk hårdvara Underliggande molninfrastruktur CUSTOMER Security IN the cloud Data Identiteter Behörigheter Konfiguration Applikationer ...beroende på vilken tjänst som används.

01 // IaaS vs PaaS vs SaaS
Modell Du får... Du hanterar typiskt...
IaaS Virtuell infrastruktur OS, applikationer, konfiguration, identiteter och data
PaaS En plattform för din applikation Applikation, data, identiteter och tjänstekonfiguration
SaaS En färdig applikation Användare, åtkomst, data och kundspecifik konfiguration

03 // SAME APPLICATION — DIFFERENT RESPONSIBILITY

Antag att Baalstorm Industries driver en webbapplikation.

IaaS

CLOUD PROVIDER ├── Datacenter ├── Physical servers └── Virtualization CUSTOMER ├── Operating system ├── Web server ├── Application ├── Accounts ├── Configuration └── Data

PaaS

CLOUD PROVIDER ├── Datacenter ├── Physical servers ├── Virtualization ├── Operating system └── Application platform CUSTOMER ├── Application ├── Accounts ├── Configuration └── Data

SaaS

CLOUD PROVIDER ├── Infrastructure ├── Operating system ├── Platform └── Application CUSTOMER ├── Users ├── Access ├── Customer configuration └── Data
