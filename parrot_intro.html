BAALSTORM // LINUX TRAINING PARROT OS BOOTCAMP
$ ./parrot-bootcamp --beginner

WELCOME TO LINUX.

Du behöver inte vara Linux-expert för att arbeta med IT-säkerhet. Men du behöver kunna hitta runt, hantera filer, läsa information och förstå vad du säger åt datorn att göra.

I den här övningen lär du dig grunderna genom att faktiskt använda terminalen i Parrot OS.

VIKTIGT

Skriv kommandona själv.
Kopiera inte bara allt utan att läsa vad kommandot gör.

Linux gör ofta exakt vad du säger åt det att göra. Det betyder inte alltid att det var vad du tänkte göra.

00 // THE TERMINAL

Vad är terminalen?

I ett grafiskt gränssnitt styr du datorn genom att klicka på ikoner och menyer.

I terminalen skriver du istället kommandon.

student@parrot:~$

Prompten innehåller information.

student @ parrot : ~ $ │ │ │ │ │ │ │ └── terminalen väntar på ett kommando │ │ │ │ │ └───── aktuell katalog │ │ │ └─────────── datorns namn │ └─────────────────── användaren
Tecknet ~ betyder din hemkatalog.

02 // WHERE AM I?

BASIC 5p

pwd — Print Working Directory

pwd

Exempel:

/home/student

Linux har inte enhetsbokstäver som C:\ på samma sätt som Windows. Filsystemet utgår istället från:

/

Det kallas root-katalogen.

03 // WHAT IS HERE?

BASIC 5p

ls — lista filer

ls

Testa sedan:

ls -l

Och:

ls -la

ls visar filer och kataloger.

ls -l visar mer information.

ls -la visar dessutom dolda filer, vilka i Linux normalt börjar med punkt.

.bashrc .profile .config

04 // MOVE AROUND

BASIC 8p

cd — Change Directory

Gå till Documents:

cd ~/Documents

Kontrollera:

pwd

Gå tillbaka en katalog:

cd ..

Gå direkt hem:

cd ~

Eller bara:

cd
. betyder aktuell katalog.
.. betyder katalogen ovanför.
~ betyder din hemkatalog.

05 // TAB IS YOUR FRIEND

SURVIVAL SKILL 5p

Tab completion

Skriv:

cd ~/Doc

Tryck sedan TAB.

Terminalen kan automatiskt komplettera fil- och katalognamn.

Använd TAB completion. Det sparar tid och minskar stavfel.

Testa även ↑ och ↓ för att bläddra bland tidigare kommandon.

BASIC 10p

cd ~

mkdir baalstorm_lab

07 // CREATE FILES

BASIC 10p

touch och echo

Skapa en tom fil:

touch notes.txt

Kontrollera:

ls -l

Skriv text till en annan fil:

echo "Baalstorm Linux Lab" > mission.txt

Läs filen:

cat mission.txt
Tecknet > skickar resultatet till en fil.

08 // APPEND

INTERMEDIATE 10p

> eller >> ?

Kör:

echo "Line 1" > log.txt echo "Line 2" >> log.txt echo "Line 3" >> log.txt

Läs filen:

cat log.txt

> skriver till filen och ersätter tidigare innehåll.

>> lägger till information sist i filen.

09 // COPY, MOVE, DELETE

FILE OPS 10p

cp / mv / rm

Kopiera:

cp mission.txt mission_backup.txt

Byt namn:

mv mission_backup.txt secret.txt

Kontrollera:

ls -l

Skapa en testfil:

touch delete_me.txt

Ta bort den:

rm delete_me.txt
rm betyder REMOVE.

Terminalen har normalt ingen papperskorg för filer som tas bort med rm. Kontrollera därför kommandot innan du trycker Enter.

10 // READ FILES

FILE OPS 8p

cat, less, head och tail

Skapa lite data:

seq 1 100 > numbers.txt

Testa:

head numbers.txt
tail numbers.txt
less numbers.txt

I less kan du scrolla och trycka q för att avsluta.

11 // FIND THE NEEDLE

INTERMEDIATE 12p

grep — sök i text

Skapa en logg:

echo "INFO User login" > security.log echo "INFO File opened" >> security.log echo "WARNING Failed login" >> security.log echo "INFO User logout" >> security.log echo "WARNING Failed login" >> security.log

Visa bara WARNING:

grep "WARNING" security.log

Räkna hur många:

grep -c "WARNING" security.log
Att kunna söka i text och loggar är en av de viktigaste Linux-färdigheterna för en säkerhetsanalytiker.

12 // PIPES

INTERMEDIATE 15p

| — koppla ihop kommandon

Testa:

cat security.log | grep "WARNING"

Tecknet | kallas pipe. Resultatet från ett kommando skickas till nästa.

COMMAND A | | OUTPUT v COMMAND B

Testa:

ls -la | less

Och:

cat security.log | grep "WARNING" | wc -l

Först läses filen. Sedan filtrerar grep fram WARNING. Till sist räknar wc -l antalet rader.

13 // FIND FILES

INTERMEDIATE 10p

find

Skapa några filer:

touch report.txt touch passwords.old touch image.jpg

Hitta alla txt-filer:

find . -name "*.txt"

Hitta filen passwords.old:

find . -name "passwords.old"
Punkten efter find betyder: börja söka från katalogen där jag befinner mig.

14 // PERMISSIONS

SECURITY 15p

Vem får göra vad?

Kör:

ls -l

Du kan exempelvis se:

-rw-r--r-- 1 student student 42 mission.txt

Den första delen beskriver rättigheter.

- rw- r-- r-- │ │ │ │ │ └── others │ └────── group └─────────── owner r = read w = write x = execute

Skapa ett enkelt shellscript:

echo '#!/bin/bash' > hello.sh echo 'echo "Hello from Baalstorm"' >> hello.sh

Kontrollera rättigheterna:

ls -l hello.sh

Gör filen körbar:

chmod +x hello.sh

Kör:

./hello.sh

15 // ROOT & SUDO

SECURITY 10p

Med stora krafter...

Linux har en superuser som heter root. Root kan göra nästan vad som helst på systemet.

Kommandot sudo används för att köra ett kommando med förhöjda rättigheter när användaren har tillstånd.

sudo COMMAND
Använd inte sudo bara för att ett kommando inte fungerar. Förstå först varför kommandot behöver högre rättigheter.

Least privilege.

Arbeta med vanliga användarrättigheter och använd högre behörighet endast när den faktiskt behövs.

20 // CONNECTIONS

SECURITY 15p

Vilka portar används?

Kör:

ss -tuln

Flaggorna betyder:

t = TCP u = UDP l = listening n = visa numeriska adresser/portar

Här kan du se vilka TCP- och UDP-portar som lyssnar på datorn.

En lyssnande tjänst innebär att ett program väntar på nätverkskommunikation.

För en säkerhetsanalytiker är det relevant att veta vilka tjänster som är exponerade och om de faktiskt behövs.

23 // SECURITY LOG CHALLENGE

CHALLENGE 25p

Hitta attacken

Skapa loggfilen:

cat > auth.log << 'EOF' 10:01 LOGIN alice SUCCESS 10:02 LOGIN bob SUCCESS 10:03 LOGIN admin FAILED 10:03 LOGIN admin FAILED 10:04 LOGIN admin FAILED 10:05 LOGIN charlie SUCCESS 10:06 LOGIN root FAILED 10:07 LOGIN admin FAILED 10:08 LOGIN alice SUCCESS EOF

Nu ska du ta reda på hur många misslyckade inloggningar som finns.

Försök lösa det med grep, pipe och wc.

grep "FAILED" auth.log | wc -l

Resultat:

5

Visa endast misslyckade försök för admin:

grep "admin" auth.log | grep "FAILED"

24 // TERMINAL BOSS

BOSS 40p

Operation LOST FLAG

MISSION BRIEFING En fil har gömts någonstans i: ~/baalstorm_boss/ Du får INTE använda den grafiska filhanteraren. Intel: FILE TYPE: .txt FILE CONTENT: BAALSTORM_FLAG OBJECTIVE: Find the file. Read the flag.

Förbered bossen

Kör detta först:

mkdir -p ~/baalstorm_boss/{docs,logs,backup,tmp} echo "nothing here" > ~/baalstorm_boss/docs/readme.txt echo "system normal" > ~/baalstorm_boss/logs/system.txt echo "old backup" > ~/baalstorm_boss/backup/backup.txt echo "BAALSTORM_FLAG{terminal_operator}" > ~/baalstorm_boss/tmp/.system_notes.txt

Rensa terminalen:

clear
Nu börjar bossen.

Använd det du har lärt dig.
Öppna inte filhanteraren.
Vilket kommando använde du för att hitta filen?

_____________________________________________________

Vad heter filen?

_____________________________________________________

Vilken flagga innehåller den?

_____________________________________________________

Eftersom filen kan vara dold:

find ~/baalstorm_boss -type f

Det avslöjar bland annat:

/home/.../baalstorm_boss/tmp/.system_notes.txt

Läs filen:

cat ~/baalstorm_boss/tmp/.system_notes.txt

Flaggan:

BAALSTORM_FLAG{terminal_operator}

En annan metod är att söka efter innehållet:

grep -R "BAALSTORM_FLAG" ~/baalstorm_boss
