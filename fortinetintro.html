01 // LOGIN & DASHBOARD

STEP 01

Logga in

Koppla en dator till ett LAN-interface på FortiGate-enheten.

Öppna webbläsaren och anslut till den management-IP som är angiven på brandväggen eller av läraren.

https://<fortigate-ip>

Webbläsaren kan visa certifikatvarning i labbet. Kontrollera att du ansluter till rätt labbenhet.

Logga in med credentials som finns märkta på brandväggen.

STEP 02

Dashboard

Dashboard visar bland annat:

• Hostname

• Firmware-version

• Systemtid

• Uptime

• WAN-status

• Aktiva administratörer

I utbildningsmiljön kan FortiGuard-funktioner visa varningar eller sakna licens. Det är inte ett problem för dessa grundövningar.

02 // NETWORK INTERFACES

STEP 03

Hitta interfaces

Network → Interfaces

Här ser du FortiGate-enhetens portar och logiska interfaces.

För varje interface bör du kunna hitta:

• Namn, exempelvis port1 / port2 / internal

• IP-adress

• Interface role, exempelvis LAN eller WAN

• Administrativ status

• Fysisk länkstatus

Vilket interface är din dator ansluten till? Vilken IP-adress har FortiGate på det interfacet?

03 // ROUTING

STEP 04

Routingtabellen

FortiGate måste veta vart trafik ska skickas.

Network → Static Routes

Leta efter en default route:

0.0.0.0/0

Den används normalt för trafik till nät som inte finns direkt anslutna till brandväggen.

04 // FIREWALL POLICY

STEP 05

Policy & Objects

Policy & Objects → Firewall Policy

Här finns reglerna som avgör vilken trafik som får passera mellan interfaces eller zoner.

Incoming Interface – var trafiken kommer från

Outgoing Interface – vart trafiken ska

Source – källadress

Destination – destinationsadress

Service – protokoll/port

Action – ACCEPT eller DENY

NAT – om adressöversättning ska användas

STEP 06

Regelordning

FortiGate utvärderar brandväggspolicies uppifrån och ned.

Policy 1 Policy 2 Policy 3 ... Implicit deny

Första matchande policy används.

Om ingen policy matchar blockeras trafiken normalt av implicit deny.

05 // SESSIONS

STEP 07

Stateful firewall

FortiGate håller normalt reda på aktiva anslutningar i en session table.

Om en klient initierar en tillåten TCP-session kan brandväggen känna igen returtrafiken som en del av samma session.

CLIENT → SERVER:443 ACCEPT SERVER:443 → CLIENT existing session ACCEPT

Detta är kärnan i en stateful firewall.

06 // LOGS

STEP 08

Verifiera vad som händer

När loggning finns aktiverad kan du använda trafikloggar för att se vilken policy som matchade trafiken.

Exakt meny kan skilja sig beroende på firmware och konfiguration, men leta efter trafik- eller forward traffic-loggar.

Source IP

Destination IP

Service / port

Action

Policy ID
