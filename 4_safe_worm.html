BAALSTORM // MALWARE LAB SAFE WORM SIMULATOR
$ ./safe-worm --simulate --observe

BUILD A WORM.

I den här labben bygger ni en ofarlig simulering av en datormask. Programmet kommer att kopiera sig självt och skapa spår som går att analysera — men det får endast arbeta i sin egen labbkatalog.

Efteråt testar ni Windows Defender med EICAR, en testfil som är skapad för att antivirusprogram ska reagera utan att riktig skadlig kod används.

⚠ SAFETY RULES

Detta är en simulering.

Skriptet får INTE:
• använda nätverket
• kontakta andra datorer
• skriva i registret
• använda Startup-mappar
• skapa Scheduled Tasks
• kräva administratörsrättigheter
• modifiera riktiga användarfiler
• arbeta utanför sin egen labbkatalog

00 // WHAT ARE WE SIMULATING?

En riktig mask kan sprida sig automatiskt från system till system. Det tänker vi inte göra här.

Istället skapar vi tre kataloger som representerar tre datorer:

C:\Users\...\AppData\Local\Temp\BaalstormSafeWorm\ NODE-A NODE-B NODE-C

När vår simulator "sprider sig" kopierar den bara sig själv mellan dessa kataloger.

VIKTIGT:

NODE-A, NODE-B och NODE-C är bara mappar på samma dator.
Ingen riktig nätverksspridning sker.

01 // CREATE THE LAB DIRECTORY

TASK 01 5p

Skapa labbmiljön

Öppna PowerShell och kör:

$Lab = "$env:TEMP\BaalstormSafeWorm" New-Item -ItemType Directory -Force -Path $Lab New-Item -ItemType Directory -Force -Path "$Lab\NODE-A" New-Item -ItemType Directory -Force -Path "$Lab\NODE-B" New-Item -ItemType Directory -Force -Path "$Lab\NODE-C" Write-Host "Lab created:" Write-Host $Lab

Kontrollera resultatet:

Get-ChildItem "$env:TEMP\BaalstormSafeWorm"

Ni bör se:

NODE-A NODE-B NODE-C

02 // BUILD THE SAFE WORM

TASK 02 15p

Skapa SafeWorm.ps1

Öppna Notepad och skapa filen:

SafeWorm.ps1

Klistra in följande kod:

$LabRoot = "$env:TEMP\BaalstormSafeWorm" $Nodes = @( "$LabRoot\NODE-A", "$LabRoot\NODE-B", "$LabRoot\NODE-C" ) $LogFile = "$LabRoot\worm.log" Write-Host "" Write-Host "====================================" -ForegroundColor Green Write-Host " BAALSTORM SAFE WORM SIMULATOR" -ForegroundColor Green Write-Host "====================================" -ForegroundColor Green Write-Host "" if (!(Test-Path $LabRoot)) { Write-Host "Lab directory missing." Write-Host "Creating safe environment..." New-Item -ItemType Directory -Force -Path $LabRoot | Out-Null foreach ($Node in $Nodes) { New-Item -ItemType Directory -Force -Path $Node | Out-Null } } $Timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss" Add-Content $LogFile "$Timestamp SAFEWORM STARTED" Write-Host "[1] Discovering simulated nodes..." Start-Sleep -Milliseconds 700 foreach ($Node in $Nodes) { Write-Host " FOUND: $Node" Add-Content $LogFile "$Timestamp NODE_DISCOVERED $Node" Start-Sleep -Milliseconds 500 } Write-Host "" Write-Host "[2] Simulating propagation..." $SourceCode = @' # BAALSTORM SAFE WORM COPY # # This file is harmless. # It does not execute or spread. # # SIMULATED WORM ARTIFACT '@ foreach ($Node in $Nodes) { $Target = Join-Path $Node "SafeWorm-Copy.ps1" Set-Content -Path $Target -Value $SourceCode Write-Host " COPY -> $Target" Add-Content $LogFile "$Timestamp SIMULATED_COPY $Target" Start-Sleep -Milliseconds 600 } Write-Host "" Write-Host "[3] Creating simulated persistence indicators..." foreach ($Node in $Nodes) { $PersistenceFile = Join-Path $Node "SIMULATED_PERSISTENCE.txt" Set-Content ` -Path $PersistenceFile ` -Value "SIMULATION ONLY - no persistence was created." Write-Host " INDICATOR -> $PersistenceFile" Add-Content ` $LogFile ` "$Timestamp SIMULATED_PERSISTENCE $PersistenceFile" } Write-Host "" Write-Host "[4] Creating simulated C2 indicators..." foreach ($Node in $Nodes) { $C2File = Join-Path $Node "SIMULATED_C2.txt" Set-Content ` -Path $C2File ` -Value @" SIMULATION ONLY This file represents what a malware analyst might observe if malware attempted to contact a Command & Control server. NO NETWORK CONNECTION WAS MADE. Example fictional destination: 203.0.113.55:443 "@ Write-Host " FAKE C2 -> $C2File" Add-Content ` $LogFile ` "$Timestamp SIMULATED_C2 $C2File" } Write-Host "" Write-Host "[5] Simulation complete." -ForegroundColor Green Write-Host "" Write-Host "Artifacts:" Write-Host $LabRoot Write-Host "" Write-Host "Log:" Write-Host $LogFile Write-Host "" Write-Host "NO NETWORK TRAFFIC WAS GENERATED." -ForegroundColor Yellow Write-Host "NO SYSTEM PERSISTENCE WAS CREATED." -ForegroundColor Yellow Write-Host "NO REAL USER FILES WERE MODIFIED." -ForegroundColor Yellow
Skriptet använder endast: $env:TEMP\BaalstormSafeWorm Det simulerar beteenden genom att skapa textfiler och kopior inne i labbkatalogen.

05 // HASH THE ARTIFACTS

FORENSICS 10p

Digitala fingeravtryck

Beräkna SHA256 för en av kopiorna:

Get-FileHash "$env:TEMP\BaalstormSafeWorm\NODE-A\SafeWorm-Copy.ps1" -Algorithm SHA256

Gör samma sak för NODE-B:

Get-FileHash "$env:TEMP\BaalstormSafeWorm\NODE-B\SafeWorm-Copy.ps1" -Algorithm SHA256

Jämför hashvärdena.

Eftersom filerna innehåller samma data bör de få samma hash.

Det illustrerar varför hashvärden kan användas som ett digitalt fingeravtryck för filer.

06 // MALWARE BEHAVIOR

ANALYSIS 15p

Vad hade varit farligt i en riktig mask?

Simulatorn gjorde följande:

DISCOVERY SELF-COPY PERSISTENCE SIMULATION C2 SIMULATION LOGGING

Vilka av dessa beteenden skulle kunna vara misstänkta om de utfördes av ett okänt program på riktigt?

Självkopiering kan indikera spridningsförsök.

Persistence-försök kan innebära att ett program försöker överleva omstart eller inloggning.

Kontakt med en extern C2-server är också ett klassiskt beteende som endpoint- och nätverkssäkerhet kan reagera på.

07 // CAN DEFENDER DETECT IT?

DEFENDER 10p

Kommer SafeWorm att blockeras?

Kanske inte.

SafeWorm gör medvetet väldigt lite som är farligt. Det skriver bara filer i en labbkatalog.

Det är viktigt: Vi försöker INTE göra skriptet mer malware-likt bara för att lura fram en Defender-varning. Istället använder vi ett officiellt antivirus-test.

08 // EICAR TEST

ANTIMALWARE TEST 20p

Kan vi få Defender att reagera säkert?

Ja.

EICAR är en standardiserad testfil som är avsedd för att kontrollera antivirusprogram.

EICAR är inte ett riktigt virus. Testfilen är skapad för att antivirusprodukter ska identifiera den som om den vore skadlig.

Gå till den officiella EICAR-sidan:

https://www.eicar.org/download-anti-malware-testfile/

Försök ladda ner standardtestfilen.

Windows Defender kan reagera redan i webbläsaren, vid nedladdningen eller när filen skrivs till disk.

Vad hände?

[ ] Webbläsaren blockerade filen

[ ] Defender blockerade filen

[ ] Filen skapades och sattes sedan i karantän

[ ] En säkerhetsnotifikation visades

[ ] Något annat

10 // AV VS EDR

SECURITY THINKING 15p

Två olika sätt att upptäcka hot

EICAR KNOWN SIGNATURE | v ANTIVIRUS UNKNOWN PROGRAM SUSPICIOUS BEHAVIOR | v EDR / BEHAVIOR ANALYSIS

Vad är skillnaden mellan dessa två typer av detektion?

EICAR illustrerar signaturbaserad detektion. Antiviruset känner igen ett känt mönster.

EDR kan istället reagera på vad ett program gör, även om själva filen inte matchar en känd malware-signatur.

Moderna endpoint-lösningar kombinerar ofta båda metoderna.

Självkopieringen liknar maskbeteende.

Persistence-filen representerar ett möjligt persistence-försök, men i denna labb skapas ingen riktig persistence.

C2-filen är endast en indikator i simulatorn. Nätverksloggen visar att ingen riktig anslutning gjordes.

Hashvärden, filnamn, sökvägar och logghändelser skulle kunna användas som IoC:er i en riktig incident.
