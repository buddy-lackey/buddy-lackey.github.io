Lecture 01

INTRODUCTION TO CYBER SECURITY

Cyber security becomes easier to reason about if we start with three simple questions: What are we trying to protect? Why does it need protection? How do we protect it?

WHAT? Security properties such as confidentiality, integrity and availability.
WHY? Assets exist. Threats exist. Vulnerabilities create opportunities for those threats.
HOW? Principles, mechanisms and concrete security controls.
// WHAT ARE WE PROTECTING?
CHALLENGE 01

The disappearing server

A company's customer portal is attacked and becomes unreachable for six hours. No customer information is stolen and no data is modified.

Which property of the CIA triad has primarily been affected?

Bonus: Can confidentiality and integrity still be intact while security has failed?

Reveal discussion
Availability is the primary property affected. Yes — the data can remain confidential and correct while the service is unavailable. Security is not only about secrecy.
CHALLENGE 02

One incident, three properties

An attacker gains access to a student database, reads exam results, changes several grades, and finally deletes the database.

Identify what happened to Confidentiality, Integrity and Availability.

Reading information without permission = ?
Changing information without permission = ?
Deleting the database = ?
Could more than one property fail in the same incident?
Reveal discussion
Unauthorized reading affects Confidentiality. Unauthorized modification affects Integrity. Deleting the database affects Availability. A single attack can affect all three.
// WHY DO WE NEED SECURITY?
CHALLENGE 03

Asset, threat or vulnerability?

A company has an Internet-facing VPN server containing an unpatched vulnerability. An attacker on the Internet discovers the server and attempts to exploit it to access internal systems.

Identify the asset, threat and vulnerability in this scenario.

Reveal discussion
Possible assets include the VPN service, credentials, internal systems and business information. The attacker represents the threat. The unpatched flaw is the vulnerability. The vulnerability alone is not the threat, and the attacker alone is not the asset.
CHALLENGE 04

Which one matters most?

System A contains a serious vulnerability but is disconnected from all networks and contains no valuable information. System B contains employee payroll information and is reachable from several internal networks.

Which system should receive more security attention?

There is deliberately no perfect one-line answer. Discuss what information you would need before deciding.

Reveal discussion
Vulnerability severity alone does not determine risk. Asset value, exposure, likelihood, existing controls and potential impact all matter.
// HOW DO WE CREATE SECURITY?
CHALLENGE 05

AAA investigation

Match each event to Authentication, Authorization or Accounting.

09:41:03 User alice submits password and security key

09:41:05 System confirms identity: alice

09:41:12 alice attempts to open /finance/payroll.xlsx

09:41:12 ACCESS DENIED — insufficient privileges

09:41:12 Event written to security audit log

Where can you see Authentication, Authorization and Accounting?

Reveal discussion
Authentication establishes that the user is Alice. Authorization determines whether Alice is permitted to access payroll.xlsx. Accounting records the security event for later auditing or investigation.
CHALLENGE 06

One lock or many?

An organisation says: "Our firewall protects the network. If the firewall works, we don't need additional protection."

Which security principle challenges this way of thinking?

Give at least four different layers that could protect an important server.

Reveal discussion
Defense in Depth. Possible layers include network filtering, segmentation, authentication, authorization, endpoint protection, hardening, monitoring, encryption and backups. The important idea is that failure of one control should not automatically mean total compromise.
