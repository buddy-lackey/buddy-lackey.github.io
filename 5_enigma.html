00 // FROM CAESAR TO ENIGMA

WARMUP 5p

Caesar-chiffer

PLAINTEXT: AAAAAA CAESAR +3: DDDDDD

Vilken information läcker chiffertexten?

Samma bokstav blir alltid samma bokstav.

Mönster i klartexten finns därför tydligt kvar i chiffertexten. Det ger mycket dålig diffusion och ett enkelt samband mellan nyckeln och chiffertexten.

02 // WHY THE ROTORS MATTER

INTERMEDIATE 10p

Antag att samma bokstav skrivs flera gånger:

INPUT: AAAAAA POSSIBLE ENIGMA OUTPUT: GPKZWM

Varför behöver samma bokstav inte bli samma chifferbokstav varje gång?

Rotorerna flyttar sig medan operatören skriver.

Det innebär att substitutionen förändras mellan olika positioner i meddelandet.

Det är en stor förbättring jämfört med Caesar-chiffer, där samma bokstav alltid behandlas på samma sätt.

03 // CONFUSION

SHANNON 15p
CAESAR KEY = +3 A → D B → E C → F ENIGMA KEY = rotor choice rotor order rotor positions ring settings plugboard settings A → ?

Vilken maskin har bäst confusion?

CAESAR / ENIGMA

Förklara varför.

Enigma.

Sambandet mellan nyckelkonfiguration och chiffertext är mycket mer komplicerat än i Caesar-chiffret.

Plugboard, rotorordning, rotorpositioner och rotorernas interna kopplingar kombineras för att skapa en stor mängd möjliga substitutioner.

Enigma hade därför betydligt bättre confusion än enkla substitutionschiffer.

04 // THE DIFFUSION PROBLEM

SHANNON 20p

Antag att vi krypterar:

MESSAGE 1: ATTACK AT DAWN MESSAGE 2: ATTACK AT DAWM ^ ONE LETTER CHANGED

Maskinen startar från exakt samma inställning i båda fallen.

Vad händer med chiffertexten efter att den ändrade bokstaven har behandlats?

A) Nästan hela chiffertexten förändras.

B) Primärt motsvarande chifferbokstav förändras.

C) Hela rotorinställningen förstörs.

B.

Enigma behandlar varje tecken med den maskinposition som gäller just då.

En ändrad klartextbokstav ändrar inte i sig rotorernas fortsatta stegring.

Därför sprids inte effekten av en liten klartextändring över många efterföljande chiffertecken på det sätt vi förväntar oss av moderna blockchiffer.

Detta är Enigmas stora svaghet när vi analyserar den med begreppet diffusion.

05 // MODERN AVALANCHE

MODERN CRYPTO 15p
MODERN BLOCK CIPHER PLAINTEXT A: 011010001101... PLAINTEXT B: 011010001100... ^ 1 BIT CIPHERTEXT A: 1011011100101001... CIPHERTEXT B: 0100100011110110...

Vad försöker den moderna algoritmen uppnå?

En liten förändring i indatan ska påverka stora delar av utdata.

Det kallas avalanche-effekt och är nära kopplat till god diffusion.

06 // A STRANGE ENIGMA PROPERTY

STRUCTURAL WEAKNESS 20p

På Enigma kunde en bokstav aldrig krypteras till sig själv.

A → NOT A B → NOT B C → NOT C ...

Varför kan en sådan regel vara dålig ur kryptografisk synvinkel?

Det ger angriparen information om vad ett visst tecken inte kan vara.

Om angriparen misstänker att ett visst känt ord förekommer i meddelandet kan positioner där en bokstav skulle motsvara sig själv direkt uteslutas.

Sådana förutsägbara strukturer minskar angriparens sökutrymme.

07 // CRIBS

CRYPTANALYSIS 20p

Antag att en angripare misstänker att många meddelanden innehåller:

WETTER eller HEILHITLER eller andra återkommande formuleringar

Ett sådant förmodat stycke klartext kallas ofta en crib.

Hur kan känd eller gissad klartext hjälpa en angripare?

Angriparen kan jämföra den misstänkta klartexten med chiffertexten och testa möjliga maskininställningar.

Strukturella egenskaper hos Enigma, exempelvis att en bokstav inte kan krypteras till sig själv, kan hjälpa till att snabbt utesluta många felaktiga positioner och inställningar.

08 // HUMAN FACTOR

OPSEC 15p

En mycket stark kryptomaskin kan fortfarande användas dåligt.

Possible operator mistakes: - predictable messages - repeated phrases - reused settings - poor procedures - incorrect key handling

Vilken säkerhetsprincip känner du igen här?

Kryptografins säkerhet beror inte bara på själva algoritmen. Nyckelhantering och operativa rutiner spelar också stor roll.

En stark algoritm kan undermineras av svag implementation eller dåliga rutiner.

1. Rotorernas rörelse innebär att samma klartextbokstav inte alltid ger samma chifferbokstav. Det är betydligt bättre confusion än Caesar-chiffer.

2. Om en klartextbokstav ändras påverkas inte automatiskt många andra chiffertecken. Det visar svag diffusion jämfört med moderna blockchiffer.

3. Regeln att en bokstav aldrig kan krypteras till sig själv ger angriparen information som kan användas för att utesluta möjliga lösningar.

4. Förutsägbara meddelanden ger möjlig känd klartext, så kallade cribs.

5. Substitution, flera transformationssteg och nyckelberoende transformationer är idéer som även finns i modern kryptografi.

6. Moderna blockchiffer skapar mycket starkare diffusion och avalanche-effekt och är konstruerade för att minimera användbara strukturella samband.

13 // FINAL QUESTION

FINAL 25p

Var Enigma dålig kryptografi?

Svara inte bara JA eller NEJ. Resonera kring: • sin samtid
• nyckelrymd
• confusion
• diffusion
• strukturella egenskaper
• operatörsfel
• kryptanalys

Enigma var mycket avancerad jämfört med tidigare handchiffer och skapade ett enormt mer komplicerat substitutionssystem.

Problemet var inte enbart att "nyckeln var för liten". Maskinen hade strukturella egenskaper och begränsad diffusion som kunde kombineras med känd klartext, operativa misstag och kraftfull kryptanalys.

Det är en viktig lärdom även idag: en stor nyckelrymd gör inte automatiskt ett kryptosystem säkert.
